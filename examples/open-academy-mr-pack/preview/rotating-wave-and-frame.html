自旋磁矩与驱动哈密顿量

直接前置依赖：量子力学与数学预备基础（qm-spin-and-operators-foundation）

为什么先统一磁共振与量子光学的起点哈密顿量？

把可控的二能级量子系统放进外场里，第一步总要写出它的静态能级劈裂与外部交变驱动项。在自旋磁共振中，静磁场配合横向交变磁场耦合自旋磁矩；在量子光学中，二能级原子的电偶极矩则与激光电场耦合。

虽然载体与能级差相差几个数量级，两者的数学骨架却完全同构。本课先把磁共振的标准起点 $H = \omega_0 S_z + 2\Omega\cos(\omega t+\varphi)S_x$ 推导透彻，再把符号映射到《量子光学》二能级原子模型，为下一课消去时间依赖打好基础。

第 1 课 Step 1 · zeeman-gyromagnetic-and-splitting

用旋磁比确定塞曼分裂与能级顺序

本步要点 (TL;DR)
  • 自旋磁矩满足 $\vec{\boldsymbol{\mu}} = \gamma\vec{\boldsymbol{S}}$，静磁场中相互作用为 $H_0 = -\gamma B_0 S_z$（$\hbar = 1$）。
  • 电子旋磁比 $\gamma_e < 0$（约 $-2\pi\times 2.8\text{ MHz/G}$），使 $|m_S = -1/2\rangle$ 成为下能级、$|m_S = +1/2\rangle$ 成为上能级。
  • 质子等核自旋 $\gamma_n > 0$（$\text{kHz/G}$ 量级，比电子小约 $10^3$ 倍），能级上下顺序恰好反转。

从磁矩耦合到静态哈密顿量

自旋可以等效为一个微型磁偶极子。在外磁场 $\boldsymbol{B}$ 中，自旋磁矩 $\vec{\boldsymbol{\mu}}$ 的相互作用能为 $H = -\vec{\boldsymbol{\mu}}\cdot\boldsymbol{B}$。磁矩与自旋角动量算符 $\vec{\boldsymbol{S}}$ 成正比：

$$\vec{\boldsymbol{\mu}} = \gamma\vec{\boldsymbol{S}}$$

比例系数 $\gamma$ 称为旋磁比。若把哈密顿量两边同除以 $\hbar$，就可以把角频率当作能量单位，此时 $\vec{\boldsymbol{S}} = (S_x, S_y, S_z)$ 是无量纲自旋算符（满足 $S_z|m_S=\pm 1/2\rangle = \pm\frac{1}{2}|m_S=\pm 1/2\rangle$）。仅加沿 $+z$ 轴的静磁场 $\boldsymbol{B}_0 = B_0\vec{\boldsymbol{e}}_z$（$B_0 > 0$）时，静态哈密顿量为

$$H_0 = -\gamma B_0 S_z$$

比较电子自旋与核自旋的旋磁比

电子带负电，自由电子 $\gamma_e = g_s \frac{-|e|}{2m_e} \approx -2\pi\times 2.8025\text{ MHz/G}$（金刚石 NV 色心受晶体环境影响，约为 $-2\pi\times 2.8033\text{ MHz/G}$）。由于 $\gamma_e < 0$，我们令正参数 $\omega_0 = -\gamma_e B_0 > 0$，则 $H_0 = \omega_0 S_z$ 给 $|m_S=-1/2\rangle$ 与 $|m_S=+1/2\rangle$ 赋予能量 $-\omega_0/2$ 和 $+\omega_0/2$。

原子核质量约为电子的 $10^3$ 倍，因此核旋磁比 $\gamma_n$ 比 $|\gamma_e|$ 小 $10^3$ 到 $10^4$ 倍（例如自由质子 $\gamma_n = 2\pi\times 4.2577\text{ kHz/G}$，水中质子因化学位移约为 $2\pi\times 4.2576\text{ kHz/G}$；常见 $^{13}\text{C}$ 约为 $2\pi\times 1.07051\text{ kHz/G}$，$^{14}\text{N}$ 约为 $2\pi\times 0.30766\text{ kHz/G}$，$^{15}\text{N}$ 则因磁矩方向相反呈负值 $-2\pi\times 0.43156\text{ kHz/G}$）。对 $\gamma_n > 0$ 的质子，$-\gamma_n B_0 < 0$，低能级变为 $|m_S = +1/2\rangle$。

常见易混误区：质子的旋磁比符号应始终记为核自旋 $\gamma_n$（不要误写作电子 $\gamma_e$），判断上下能级顺序必须先看 $\gamma$ 的正负号。

Worked Example

设金刚石 NV 色心电子自旋（$\gamma_e/(2\pi) = -2.8033\text{ MHz/G}$）与旁侧质子核自旋（$\gamma_n/(2\pi) = +4.2577\text{ kHz/G}$）共同处于静磁场 $B_0 = 500\text{ G}$ 中。

  1. 计算电子自旋的静态共振频率 $\omega_0/(2\pi)$。 代入 $\omega_0 = -\gamma_e B_0$，两个负号相消为正：
    2. $$\omega_0/(2\pi) = -(-2.8033\text{ MHz/G})\times 500\text{ G} = 1401.65\text{ MHz}.$$

以普通频率 $E/h$ 表示，下能级 $|m_S = -1/2\rangle$ 对应 $-700.825\text{ MHz}$，上能级 $|m_S = +1/2\rangle$ 对应 $+700.825\text{ MHz}$。

  1. 计算质子核自旋的静态劈裂并确定基态。 因 $\gamma_n > 0$，静态哈密顿量系数 $-\gamma_n B_0 < 0$：
    2. $$|-\gamma_n B_0|/(2\pi) = 4.2577\text{ kHz/G}\times 500\text{ G} = 2128.85\text{ kHz} \approx 2.129\text{ MHz}.$$

此时 $|m_S = +1/2\rangle$ 能量为负，处于下能级，而电子劈裂频率约为质子的 $658$ 倍。

第 1 课 Step 2 · transverse-drive-hamiltonian

推导横向交变驱动的标准哈密顿量

本步要点 (TL;DR)
  • 实验室总磁场由静磁场 $B_0\vec{\boldsymbol{e}}_z$ 与含时驱动场 $(B_x\vec{\boldsymbol{e}}_x + B_z\vec{\boldsymbol{e}}_z)\cos(\omega t+\varphi)$ 构成。
  • 线圈与 $z$ 轴垂直（$\theta_B = 90^\circ$）时纵向驱动 $B_z = 0$，只留横向项 $B_x\cos(\omega t+\varphi)S_x$。
  • 对电子自旋令 $2\Omega = -\gamma_e B_x$（注意是磁场幅值 $B_x$ 而非算符 $S_x$），得到 $H = \omega_0 S_z + 2\Omega\cos(\omega t+\varphi)S_x$。

分解实验室总磁场与倾斜角几何

在磁共振实验中，除了提供能级分裂的静磁场 $\boldsymbol{B}_0 = B_0\vec{\boldsymbol{e}}_z$，还需要施加随时间振荡的交变驱动场 $\boldsymbol{B}_{\text{dri}}(t)$ 来翻转自旋：

$$\boldsymbol{B}(t) = B_0\vec{\boldsymbol{e}}_z + (B_x\vec{\boldsymbol{e}}_x + B_z\vec{\boldsymbol{e}}_z)\cos(\omega t + \varphi)$$

实际装置中，驱动场方向与 $+z$ 轴的夹角 $\theta_B$ 未必恰好是 $90^\circ$：若总振幅为 $B_{\text{dri}}$，则横向分量为 $B_x = B_{\text{dri}}\sin\theta_B$，纵向分量为 $B_z = B_{\text{dri}}\cos\theta_B$。在垂直驱动理想几何（$\theta_B = 90^\circ$）下，$B_z = 0$；若 $\theta_B \ne 90^\circ$ 带来的纵向项 $B_z$ 不为零，我们在本单元先暂忽略它，留到后面「纵向驱动与边带激发」专题专门处理。

写成频率单位的标准驱动哈密顿量

把垂直驱动磁场 $\boldsymbol{B}(t) = B_0\vec{\boldsymbol{e}}_z + B_x\cos(\omega t+\varphi)\vec{\boldsymbol{e}}_x$ 代入 $H = -\gamma\vec{\boldsymbol{S}}\cdot\boldsymbol{B}(t)$，除以 $\hbar$ 把 $\vec{\boldsymbol{S}}$ 无量纲化，就得到

$$H = -\gamma B_0 S_z - \gamma B_x S_x \cos(\omega t + \varphi)$$

对电子自旋（$\gamma = \gamma_e < 0$），我们定义两个正频率参数：共振角频率 $\omega_0 = -\gamma_e B_0$ 与半驱动幅度（拉比频率参数）$\Omega$，满足 $2\Omega = -\gamma_e B_x$（常见易混误区：定义中的系数因子是横向磁场振幅 $B_x$，绝不是自旋算符 $S_x$）。于是整条磁共振标准哈密顿量简化为

$$H = \omega_0 S_z + 2\Omega\cos(\omega t + \varphi)S_x$$

为什么要特地在 $S_x$ 前面保留系数 $2\Omega$ 而不是直接写成 $\Omega$？因为沿固定方向来回振荡的余弦场随后会一分为二，拆成正反两个等幅度的圆偏振反向旋转分量（幅值同为 $\Omega$）；提前放入因子 $2$，刚好让下一步的有效驱动强度简洁地等于 $\Omega$。

Worked Example

某电子自旋实验（$\gamma_e/(2\pi) = -2.8\text{ MHz/G}$）的静磁场 $B_0 = 200\text{ G}$，横向线圈产生的交变驱动振幅 $B_x = 10\text{ G}$，驱动频率为 $\omega$，初相位 $\varphi = \pi/3$。

  1. 求出静态项系数 $\omega_0/(2\pi)$。 将 $\gamma_e$ 与 $B_0$ 代入 $\omega_0 = -\gamma_e B_0$：
    2. $$\omega_0/(2\pi) = -(-2.8\text{ MHz/G})\times 200\text{ G} = 560\text{ MHz}.$$
  1. 求出驱动幅值系数 $2\Omega/(2\pi)$ 与 $\Omega/(2\pi)$。 由 $2\Omega = -\gamma_e B_x$ 先算出线偏振驱动项总系数，再除以 $2$ 得到单分量参数 $\Omega$：
    2. $$2\Omega/(2\pi) = -(-2.8\text{ MHz/G})\times 10\text{ G} = 28\text{ MHz},\quad \Omega/(2\pi) = 14\text{ MHz}.$$
  1. 写出频率单位下的标准哈密顿量。 将参数代入 $H = \omega_0 S_z + 2\Omega\cos(\omega t+\varphi)S_x$：
    2. $$H/(2\pi) = 560\text{ MHz}\cdot S_z + 28\text{ MHz}\cdot\cos(\omega t + \pi/3)S_x.$$

第 1 课 Step 3 · optical-electric-dipole-isomorphism

将磁共振哈密顿量映射至量子光学二能级原子

本步要点 (TL;DR)
  • 激光场满足电偶极近似 $k\cdot r \ll 1$ 后，相互作用简化为 $H_{\text{int}} = -\hat{\boldsymbol{d}}\cdot\boldsymbol{E}(t)$。
  • 二能级原子引入跃迁算符 $\hat{\sigma}_+ = |e\rangle\langle g|$、$\hat{\sigma}_- = |g\rangle\langle e|$ 与反转算符 $\hat{\sigma}_3 = |e\rangle\langle e| - |g\rangle\langle g|$。
  • 两套模型严格对应：$2S_z \leftrightarrow \hat{\sigma}_3$、$2S_x \leftrightarrow \hat{\sigma}_+ + \hat{\sigma}_-$、磁驱动参数 $\Omega \leftrightarrow V/\hbar$。

量子光学中的电偶极相互作用与宇称选择规则

把《Introductory Quantum Optics》第 4 章的二能级原子放进单色激光电场 $\boldsymbol{E}(t) = \boldsymbol{E}_0\cos(\omega t)$ 中。由于可见光波长（约 $400\text{–}700\text{ nm}$）远大于原子尺度（埃量级，$k\cdot r \ll 1$），电场在整个原子范围内可视为空间均匀，经规范变换后只留下经典的电偶极相互作用（式 4.15 与 4.19）：

$$\hat{H} = \hat{H}_A - \hat{\boldsymbol{d}}\cdot\boldsymbol{E}(t)$$

这里 $\hat{H}_A$ 是自由原子哈密顿量，基态 $|g\rangle$ 与激发态 $|e\rangle$ 的能量差为 $E_e - E_g = \hbar\omega_0$。按书中的对称约定把零能量点取在两能级正中，使 $E_e = +\frac{1}{2}\hbar\omega_0$、$E_g = -\frac{1}{2}\hbar\omega_0$。因为原子能量定态具有确定宇称而电偶极算符 $\hat{\boldsymbol{d}} = -e\hat{\boldsymbol{r}}$ 为奇宇称算符，其同态对角元严格为零（$\langle g|\hat{\boldsymbol{d}}|g\rangle = \langle e|\hat{\boldsymbol{d}}|e\rangle = 0$），电偶极只在 $|g\rangle$ 与 $|e\rangle$ 之间产生跃迁。

建立自旋与光偶极二能级系统的精确字典

引入原子跃迁算符 $\hat{\sigma}_+ = |e\rangle\langle g|$、$\hat{\sigma}_- = |g\rangle\langle e| = \hat{\sigma}_+^\dagger$，以及粒子数反转算符 $\hat{\sigma}_3 = |e\rangle\langle e| - |g\rangle\langle g|$（满足 $[\hat{\sigma}_+, \hat{\sigma}_-] = \hat{\sigma}_3$、$[\hat{\sigma}_3, \hat{\sigma}_\pm] = \pm 2\hat{\sigma}_\pm$）。令实耦合矩阵元 $V = -\langle e|\hat{\boldsymbol{d}}\cdot\boldsymbol{E}_0|g\rangle$，则 $\hat{H}_A = \frac{1}{2}\hbar\omega_0\hat{\sigma}_3$，相互作用项写作 $\hat{H}_{\text{int}} = V\cos(\omega t)(\hat{\sigma}_+ + \hat{\sigma}_-)$。两边除以 $\hbar$，得到：

$$\hat{H}/\hbar = \frac{1}{2}\omega_0\hat{\sigma}_3 + \frac{V}{\hbar}\cos(\omega t)(\hat{\sigma}_+ + \hat{\sigma}_-)$$

无量纲横向自旋算符对 $|m_S = \pm 1/2\rangle$ 的作用规则为 $S_x|m_S = \pm 1/2\rangle = \frac{1}{2}|m_S = \mp 1/2\rangle$（即 $2S_x$ 在 $\{|+1/2\rangle, |-1/2\rangle\}$ 间以矩阵元 $1$ 相互翻转）。因此将磁共振同样置于 $\hbar=1$ 角频率单位下（$H$ 对应 $\hat{H}/\hbar$，取 $\varphi=0$）并与上式并排比对：在基矢 $\{|m_S = +1/2\rangle \leftrightarrow |e\rangle,\; |m_S = -1/2\rangle \leftrightarrow |g\rangle\}$ 下，恰有 $2S_z \leftrightarrow \hat{\sigma}_3$ 与 $2S_x \leftrightarrow \hat{\sigma}_+ + \hat{\sigma}_-$。由于 $2S_x$ 直接整体对应 $(\hat{\sigma}_+ + \hat{\sigma}_-)$，故 $2\Omega S_x = \Omega(2S_x) \leftrightarrow \Omega(\hat{\sigma}_+ + \hat{\sigma}_-)$，磁共振中的 $\Omega$ 精确对应光学耦合强度 $V/\hbar$（而非 $V/(2\hbar)$）。

Worked Example

某激光实验驱动铷原子的一对电偶极共振能级，原子跃迁频率 $\omega_0/(2\pi) = 384\text{ THz}$，偶极耦合能量矩阵元满足 $V/h = V/(2\pi\hbar) = 12\text{ MHz}$。请把它完整翻译为磁共振标准哈密顿量参数。

  1. 把光学算符翻译成无量纲自旋算符。 由映射 $|e\rangle \leftrightarrow |m_S=+1/2\rangle$、$|g\rangle \leftrightarrow |m_S=-1/2\rangle$，写出两项算符替换：
    2. $$\frac{1}{2}\hat{\sigma}_3 \leftrightarrow S_z,\qquad \hat{\sigma}_+ + \hat{\sigma}_- \leftrightarrow 2S_x.$$
  1. 求出等效的驱动幅值参数 $\Omega/(2\pi)$。 直接使用 $\Omega = V/\hbar$ 关系，两边除以 $2\pi$ 得：
    2. $$\Omega/(2\pi) = \frac{V}{2\pi\hbar} = \frac{V}{h} = 12\text{ MHz},\qquad 2\Omega/(2\pi) = 24\text{ MHz}.$$
  1. 对应回等效横向磁场（对照电子 $\gamma_e/(2\pi) = -2.8\text{ MHz/G}$）。 问产生同样 $\Omega/(2\pi)=12\text{ MHz}$ 需要多大电子自旋横向交变场 $B_x$：
    2. $$B_x = \frac{2\Omega}{|\gamma_e|} = \frac{24\text{ MHz}}{2.8\text{ MHz/G}} \approx 8.57\text{ G}.$$

旋波近似与相互作用图像

直接前置依赖：自旋磁矩与驱动哈密顿量（spin-zeeman-and-drive）

什么是旋波近似与相互作用图像？

旋波近似是把沿固定方向来回振荡的驱动场拆成顺、逆时针两个旋转分量后，舍去不能激发跃迁的反向分量；相互作用图像则是切换到随驱动场一起旋转的参考系，把依然随时间变化的哈密顿量写成常系数形式。

为什么要做这两步？在静磁场和横向交变磁场下，哈密顿量带着随时间 $t$ 振荡的余弦项，很难直接看出自旋会怎样演化。先简化驱动场、再换到旋转坐标系，就能把时间 $t$ 彻底消去，为下一步求解演化铺平道路。

前置衔接（Recap）

前置回顾 · 自旋磁矩与驱动哈密顿量（spin-zeeman-and-drive）

在静磁场与垂直横向驱动下，除以 $\hbar$ 得 $H = \omega_0 S_z + 2\Omega\cos(\omega t+\varphi)S_x$（$\omega_0=-\gamma_e B_0$，$2\Omega=-\gamma_e B_x$），与电偶极原子模型 $2S_z\leftrightarrow\hat{\sigma}_3$、$2S_x\leftrightarrow\hat{\sigma}_+ + \hat{\sigma}_-$ 同构。

第 2 课 Step 1 · rwa-split-field

拆开驱动场并舍去反向项

本步要点 (TL;DR)
  • 线偏振场可拆成正反两个等幅度旋转场。
  • 电子自旋跃迁匹配逆时针 $+1$ 光子分量，反向分量在弱驱动下可舍去。
  • 若驱动太强使 $\Omega$ 可比拟能隙 $\omega_0$，旋波近似不再适用，反向项引起共振频移。

从静态能级与线偏振场出发

对于自旋 $1/2$ 的电子（如金刚石 NV 色心），无量纲算符 $S_z$ 的本征态 $|m_S = \pm 1/2\rangle$ 满足 $S_z|m_S = \pm 1/2\rangle = \pm\frac{1}{2}|m_S = \pm 1/2\rangle$。在 $B_0 > 0$ 且 $\gamma_e < 0$ 下，静态项 $H_0 = \omega_0 S_z$（$\omega_0 = -\gamma_e B_0 > 0$）给两能级赋予 $-\omega_0/2$ 与 $+\omega_0/2$ 的能量，能隙为 $\omega_0$。

再叠加沿 $x$ 轴来回振荡的横向交变驱动场（幅值参数 $2\Omega = -\gamma_e B_x$，普通频率 $\omega/(2\pi)$，初相位 $\varphi$），除以 $\hbar$ 后得

$$H = \omega_0 S_z + 2\Omega\cos(\omega t + \varphi) S_x$$

把余弦场拆成两个旋转分量

只沿 $x$ 轴来回振荡的场叫线偏振场，在 $x\text{-}y$ 平面内绕圆圈转动的场叫圆偏振场。在右端一加一减同一个 $y$ 方向自旋分量 $S_y$ 项（$S_y$ 抵消、$S_x$ 相加还原），就把线偏振拆成一正一反两个等幅度的圆偏振分量：

$$ \begin{aligned} H &= \omega_0 S_z + 2\Omega\cos(\omega t + \varphi) S_x \\ &= \omega_0 S_z + \Omega\left[\cos(\omega t + \varphi)S_x + \sin(\omega t + \varphi)S_y\right] + \underbrace{\Omega\left[\cos(\omega t + \varphi)S_x - \sin(\omega t + \varphi)S_y\right]}_{\text{①}} \end{aligned} $$

下图左侧是两能级图，右侧是从 $+z$ 轴俯视的 $x\text{-}y$ 平面分解图：

交变电磁场携带量子化的能量份，叫做光子。右图中蓝色矢量绕 $+z$ 轴逆时针旋转，称作右旋圆偏振，对应角动量 $+1$ 的光子；红色矢量项①顺时针旋转，称作左旋圆偏振，对应角动量 $-1$ 的光子。

用角动量守恒舍去反向项

电子自旋向上跃迁 $|m_S = -1/2\rangle \to |m_S = +1/2\rangle$ 时 $\Delta m_S = +1$，须吸收 $+1$ 光子（向下跃迁 $\Delta m_S = -1$ 则放出 $+1$ 光子）。相对静态项 $H_0 = \omega_0 S_z$ 对应绕 $+z$ 轴的本征进动频率 $\omega_0$，同向项仅以 $|\omega_0-\omega|$ 缓变，而项①不仅角动量 $-1$ 不守恒，还沿反方向以和频 $(\omega_0 + \omega)$ 极快振荡（即量子光学中的反旋项）。在旋波近似（Rotating-Wave Approximation，RWA）下舍去项①：

$$H \approx \omega_0 S_z + \Omega\left[\cos(\omega t + \varphi)S_x + \sin(\omega t + \varphi)S_y\right]$$

两项幅值同为 $\Omega$，舍去项①并不是因为它更小，而是角动量不守恒且方向反向。

判断旋波近似何时在强驱动下失效

旋波近似仅在驱动远弱于能隙（$\Omega \ll \omega_0$，称作弱驱动条件）且驱动频率接近共振（$\omega$ 靠近能隙 $\omega_0$）时足够准确，此时反向项迅速平均抵消。若驱动强到 $\Omega$ 可比拟 $\omega_0$，项①来不及抵消并引起共振频率偏移，就必须保留反向项再做修正。

Worked Example

我们来对一个典型的金刚石 NV 色心电子自旋实验做一次旋波近似分解。设共振普通频率（即能隙对应频率）$\omega_0 / (2\pi) = 10\text{ GHz}$，横向交变驱动场的普通频率 $\omega / (2\pi) = 9.99\text{ GHz}$、总幅值参数 $2\Omega / (2\pi) = 20\text{ MHz}$，初相位 $\varphi = 0$。

  1. 计算单个圆偏振分量的驱动幅值。 从线性项 $2\Omega\cos(\omega t) S_x$ 拆成两个圆偏振分量后，每个分量的幅值减半：
    2. $$\Omega / (2\pi) = \frac{20\text{ MHz}}{2} = 10\text{ MHz}.$$
  1. 写出完整拆解式与被舍去的反向项①。 按逆时针和顺时针分量展开后，用下括号标出顺时针项①：
    2. $$H = \omega_0 S_z + \Omega\left[\cos(\omega t)S_x + \sin(\omega t)S_y\right] + \underbrace{\Omega\left[\cos(\omega t)S_x - \sin(\omega t)S_y\right]}_{\text{①}}.$$
  1. 结合角动量守恒与弱驱动条件舍去项①。 向上跃迁需要 $\Delta m_S = +1$，只匹配角动量 $+1$ 的逆时针分量；同时驱动 $\Omega / (2\pi) = 10\text{ MHz} \ll \omega_0 / (2\pi) = 10\text{ GHz}$ 且 $\omega$ 接近 $\omega_0$，旋波近似足够准确：
    2. $$H \approx \omega_0 S_z + \Omega\left[\cos(\omega t)S_x + \sin(\omega t)S_y\right].$$

这样就把沿 $x$ 轴振荡的驱动场化简成了单一逆时针旋转驱动场。

第 2 课 Step 2 · rwa-rotating-frame

跳进旋转坐标系消去时间

本步要点 (TL;DR)
  • 相互作用图像变换相当于坐上与驱动场同频逆时针旋转的转盘去观察系统。
  • 在转盘上看，旋转的驱动矢量变成只由初相位决定的固定矢量，不再随时间变化。
  • 变换后整个哈密顿量成为常系数形式，由频率差与固定初相位共同决定。

切换到相互作用图像

经旋波近似后，驱动矢量仍以角频率 $\omega$ 绕 $z$ 轴逆时针旋转。如果我们坐上同频逆时针旋转的参考系去观察，转动的矢量就会静止下来。

量子力学中实现这一参考系切换的算符叫相互作用图像变换，定义为 $U_i = e^{-i\omega t S_z}$，其中 $i$ 是虚数单位（$i^2 = -1$）。$U_i$ 是幺正算符，即它的厄米共轭 $U_i^\dagger$（把数值取复共轭、算符共轭转置并倒换乘积次序）恰好等于它的逆算符，满足 $U_i^\dagger U_i = \mathbb{1}$（单位算符）。由于 $S_z$ 自身厄米（$S_z^\dagger = S_z$），取共轭后指数变号，即 $U_i^\dagger = e^{+i\omega t S_z}$。

设实验室系态矢量为 $|\psi\rangle$，旋转系里的态矢量记为 $|\psi_I\rangle = U_i^\dagger|\psi\rangle$，即 $|\psi\rangle = U_i|\psi_I\rangle$。将其代入含时薛定谔方程 $i\frac{\partial}{\partial t}|\psi\rangle = H|\psi\rangle$，左侧由偏导乘积法则展开得到 $i\left(\frac{\partial}{\partial t}U_i\right)|\psi_I\rangle + U_i\, i\frac{\partial}{\partial t}|\psi_I\rangle = H U_i|\psi_I\rangle$。两边左乘 $U_i^\dagger$ 并整理出等效方程 $i\frac{\partial}{\partial t}|\psi_I\rangle = H_I|\psi_I\rangle$，其中有效哈密顿量为

$$ \begin{aligned} H_I &= U_i^\dagger H U_i - U_i^\dagger i \frac{\partial}{\partial t} U_i \\ &= (\omega_0 - \omega)S_z + \Omega \underbrace{U_i^\dagger \left[\cos(\omega t + \varphi)S_x + \sin(\omega t + \varphi)S_y\right] U_i}_{\text{②}} \end{aligned} $$

上式第一项由两部分相加得到。一方面，$S_z$ 与仅含 $S_z$ 的 $U_i$ 对易（相乘可交换顺序），所以 $U_i^\dagger(\omega_0 S_z)U_i = \omega_0 S_z U_i^\dagger U_i = \omega_0 S_z$。另一方面，$\frac{\partial}{\partial t}U_i = -i\omega S_z U_i$，代回 $-U_i^\dagger i\frac{\partial}{\partial t}U_i$ 并用 $i^2=-1$ 得出 $-\omega S_z$，相加即得 $(\omega_0 - \omega)S_z$。

用三维旋转公式化解时间依赖

令括号里旋转矢量的坐标为 $\vec{\boldsymbol{r}} = (\cos(\omega t + \varphi), \sin(\omega t + \varphi), 0)$，就可把夹在 $U_i^\dagger$ 与 $U_i$ 中间的部分写成 $\vec{\boldsymbol{r}}\cdot\vec{\boldsymbol{S}}$，整块记为项②。借助对任意自旋量子数都成立的三维旋转公式：

$$e^{-i\theta \vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}}\left(\vec{\boldsymbol{r}}\cdot\vec{\boldsymbol{S}}\right)e^{i\theta \vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}} = R_{\vec{\boldsymbol{n}}\cdot\theta}(\vec{\boldsymbol{r}})\cdot\vec{\boldsymbol{S}}$$

这里 $\vec{\boldsymbol{n}}$ 是单位方向矢量，而记号 $R_{\vec{\boldsymbol{n}}\cdot\theta}(\vec{\boldsymbol{r}})$ 里的中间点只用来分隔转轴和转角、不代表点乘，意思是把三维矢量 $\vec{\boldsymbol{r}}$ 按右手定则绕单位轴 $\vec{\boldsymbol{n}}$ 转过角度 $\theta$（右手大拇指指向 $\vec{\boldsymbol{n}}$，四指弯曲为正转角方向）。把项②左右两边同时写成 $U_i^\dagger = e^{+i\omega t S_z} = e^{-i(\omega t)(-S_z)}$ 与 $U_i = e^{-i\omega t S_z} = e^{+i(\omega t)(-S_z)}$，与公式左边两端一一比对，立刻读出 $\vec{\boldsymbol{n}} = (0, 0, -1)$ 且 $\theta = \omega t$。

绕 $(0, 0, -1)$ 转动 $\omega t$ 就是沿着橙色箭头顺时针转回 $\omega t$ 角度，黑色矢量 $\vec{\boldsymbol{r}}$ 回到只含初相位的蓝色固定矢量 $\vec{\boldsymbol{r}}' = (\cos\varphi, \sin\varphi, 0)$，从而把整个哈密顿量变成与时间无关的常系数形式：

$$H_I = (\omega_0 - \omega)S_z + \Omega\left[\cos(\varphi)S_x + \sin(\varphi)S_y\right]$$

在这个式子里，驱动初相位 $\varphi$ 决定了有效驱动轴在 $x\text{-}y$ 平面中的指向：例如 $\varphi = 0$ 时给出 $+\Omega S_x$，$\varphi = \pi/2$ 时给出 $+\Omega S_y$，$\varphi = \pi$ 时则给出 $-\Omega S_x$。

Worked Example

我们来计算一套具体参数下的旋转坐标系有效哈密顿量 $H_I$。设电子自旋共振普通频率 $\omega_0/(2\pi) = 10\text{ GHz}$，交变驱动场频率 $\omega/(2\pi) = 9.99\text{ GHz}$，单分量驱动幅值 $\Omega/(2\pi) = 10\text{ MHz}$，初相位 $\varphi = \pi/2$。

  1. 求出静态项与求导修正合并后的 $S_z$ 系数。 将 $\omega_0/(2\pi)$ 与 $\omega/(2\pi)$ 代入变换后的 $(\omega_0 - \omega)S_z$，算出 $S_z$ 项的频率系数：
    2. $$(\omega_0 - \omega)/(2\pi) = 10\text{ GHz} - 9.99\text{ GHz} = 10\text{ MHz}.$$
  1. 确定三维旋转公式参数并转回固定矢量。 这里 $\vec{\boldsymbol{n}}=(0,0,-1)$、$\theta = \omega t$，把 $\vec{\boldsymbol{r}} = (\cos(\omega t + \pi/2), \sin(\omega t + \pi/2), 0)$ 顺时针转回 $\omega t$，得到 $\vec{\boldsymbol{r}}' = (0, 1, 0)$：
    2. $$\Omega\left[\cos(\pi/2)S_x + \sin(\pi/2)S_y\right] = \Omega S_y.$$
  1. 合成最终的不含时哈密顿量 $H_I$。 将上述两项合并，并除以 $2\pi$ 以普通频率单位写出结果：
    2. $$H_I / (2\pi) = 10\text{ MHz}\cdot S_z + 10\text{ MHz}\cdot S_y.$$

所有含 $\cos(\omega t)$ 和 $\sin(\omega t)$ 的振荡项都已彻底消去，原本含时的哈密顿量变成了一个常系数算符。

用算符代数消去时间

本步要点 (TL;DR)
  • 把横向自旋算符改写成专门负责升高和降低能级的两个升降算符。
  • 在相互作用图像下，上升算符乘出一个与驱动相位恰好相消的时间因子。
  • 这套纯代数推导不仅适用于高自旋，还能直接推广到光场玻色子系统。

为什么要学升降算符

下面再学一种只靠算符代数即可消去时间的方法，便于推广到复杂驱动与光场系统。

由 $S_x, S_y$ 定义自旋升降算符：$S^+ = S_x + i S_y$ 与 $S^- = S_x - i S_y$（厄米共轭 $(S^+)^\dagger = S^-$），反解得 $S_x = \frac{1}{2}(S^+ + S^-)$、$S_y = \frac{1}{2}(-i S^+ + i S^-)$。作用在 $|m_S = \pm 1/2\rangle$ 上时，它们将磁量子数升降 $1$ 步（越界归零）：

$$ \begin{aligned} S^+|m_S = -1/2\rangle &= |m_S = +1/2\rangle, & S^+|m_S = +1/2\rangle &= 0 \\ S^-|m_S = +1/2\rangle &= |m_S = -1/2\rangle, & S^-|m_S = -1/2\rangle &= 0 \end{aligned} $$

用算符共轭消去时间

把 $S_x, S_y$ 代入项②，并用欧拉公式 $\cos\alpha \pm i\sin\alpha = e^{\pm i\alpha}$ 合并指数。利用共轭倒序法则 $(A B)^\dagger = B^\dagger A^\dagger$ 与数乘法则 $(c A)^\dagger = c^* A^\dagger$，可得 $(e^{-i(\omega t+\varphi)} U_i^\dagger S^+ U_i)^\dagger = e^{i(\omega t+\varphi)} U_i^\dagger S^- U_i$。于是括号里含 $S^-$ 的第二项恰好是第一项的厄米共轭，简记为 $h.c.$：

$$ \begin{aligned} \text{②} &= U_i^\dagger \left[\cos(\omega t + \varphi)S_x + \sin(\omega t + \varphi)S_y\right] U_i \\ &= \frac{1}{2} U_i^\dagger \left[e^{-i(\omega t + \varphi)}S^+ + e^{i(\omega t + \varphi)}S^-\right] U_i \\ &= \frac{1}{2}\left[e^{-i(\omega t + \varphi)} U_i^\dagger S^+ U_i + h.c.\right] \end{aligned} $$

根据算符函数的通用作用规则：若某算符满足 $S_z|m_S\rangle = m_S|m_S\rangle$，则函数 $f(S_z)$ 作用在该本征态上只需把 $S_z$ 换成数值 $m_S$，即 $f(S_z)|m_S\rangle = f(m_S)|m_S\rangle$。由于 $S^+$ 把 $m_S$ 抬高 $+1$，这让我们得到恒等式 $U_i^\dagger S^+ U_i = e^{i\omega t} S^+$（下方例题给出逐态证明）。代回上式，指数中的 $-i\omega t$ 与 $+i\omega t$ 立刻相消：

$$\text{②} = \frac{1}{2}\left(e^{-i\varphi} S^+ + e^{i\varphi} S^-\right) = \cos(\varphi)S_x + \sin(\varphi)S_y$$

该推导仅利用“$S^+$ 将 $m_S$ 抬高 $+1$”，故对高自旋（$S > 1/2$）与单模光场玻色子同样成立：粒子数态满足 $a^\dagger a|n\rangle = n|n\rangle$，产生算符 $a^\dagger|n\rangle = \sqrt{n+1}|n+1\rangle$ 仅比 $|n\rangle$ 多出可越过指数交换的标量系数 $\sqrt{n+1}$，而湮灭算符 $a$ 降一光子，故有 $e^{i\omega t\, a^\dagger a} a^\dagger e^{-i\omega t\, a^\dagger a} = a^\dagger e^{i\omega t}$ 及其共轭 $a e^{-i\omega t}$。

由此可直接理解全量子 Jaynes–Cummings（JC）模型：把经典光场换成频率为 $\omega$ 的单模量子光场（能量项 $\omega a^\dagger a$），与原子通过耦合常数 $\lambda$ 写成 $\lambda(\hat{\sigma}_+ + \hat{\sigma}_-)(a + a^\dagger)$（对应 $2S_x\leftrightarrow\hat{\sigma}_+ + \hat{\sigma}_-$）。不同于前文停留在驱动旋转系 $U_i$ 中直接读出常系数失谐 $(\omega_0-\omega)S_z$，若改以自由演化 $\hat{H}_0/\hbar = \frac{1}{2}\omega_0\hat{\sigma}_3 + \omega a^\dagger a$ 作相互作用图像，同理可得 $\hat{\sigma}_+ \to \hat{\sigma}_+ e^{i\omega_0 t}$，于是 $\hat{\sigma}_+ a$ 随 $(\omega_0-\omega)$ 缓变而保留，反旋项 $\hat{\sigma}_+ a^\dagger$ 随 $(\omega_0+\omega)$ 快变而舍去，得到标准 JC 哈密顿量：

$$\hat{H}_{\text{JC}}/\hbar = \frac{1}{2}\omega_0\hat{\sigma}_3 + \omega a^\dagger a + \lambda(\hat{\sigma}_+ a + \hat{\sigma}_- a^\dagger).$$

Worked Example

我们来逐步证明算符恒等式 $U_i^\dagger S^+ U_i = e^{i\omega t} S^+$，并代回 $\varphi = \pi/2$ 核对结果。因为任意自旋 $1/2$ 量子态都能写成两个本征基矢 $\{|m_S=+1/2\rangle, |m_S=-1/2\rangle\}$ 的线性叠加 $|\psi\rangle = c_+|m_S=+1/2\rangle + c_-|m_S=-1/2\rangle$，只要在两个本征基矢上分别验证等式两边相等，就由算符线性严格证明了算符恒等式对所有态都成立。

  1. 检验作用在下能级本征基矢 $|m_S = -1/2\rangle$ 上。 由规则 $f(S_z)|m_S\rangle = f(m_S)|m_S\rangle$，右侧 $U_i = e^{-i\omega t S_z}$ 作用在 $|m_S=-1/2\rangle$ 上给出 $e^{+i\omega t/2}$；被 $S^+$ 升到上态 $|m_S=+1/2\rangle$ 后，左侧 $U_i^\dagger = e^{+i\omega t S_z}$ 再给出同号因子 $e^{+i\omega t/2}$，与右端 $e^{i\omega t}S^+|m_S=-1/2\rangle$ 完全相同：
    2. $$U_i^\dagger S^+ U_i |m_S = -1/2\rangle = e^{i\omega t/2} U_i^\dagger S^+ |m_S = -1/2\rangle = e^{i\omega t/2} U_i^\dagger |m_S = +1/2\rangle = e^{i\omega t} |m_S = +1/2\rangle.$$
  1. 检验另一本征基矢 $|m_S = +1/2\rangle$。 因为 $U_i|m_S = +1/2\rangle = e^{-i\omega t/2}|m_S = +1/2\rangle$，且 $S^+|m_S = +1/2\rangle = 0$，所以左端结果为 $0$，与右端 $e^{i\omega t}S^+|m_S=+1/2\rangle = 0$ 一致，恒等式 $U_i^\dagger S^+ U_i = e^{i\omega t} S^+$ 证毕。
  1. 代回项②并核对具体参数。 将 $\varphi = \pi/2$、$(\omega_0 - \omega)/(2\pi) = 10\text{ MHz}$、$\Omega/(2\pi) = 10\text{ MHz}$ 代入无时间依赖的项②：
    2. $$\text{②} = \frac{1}{2}\left(e^{-i\pi/2} S^+ + e^{i\pi/2} S^-\right) = \frac{1}{2}\left(-i S^+ + i S^-\right) = S_y.$$

于是 $H_I/(2\pi) = 10\text{ MHz}\cdot S_z + 10\text{ MHz}\cdot S_y$，升降算符法与三维旋转公式法所得的常系数哈密顿量完全吻合。

第 3 课 Step 1 · su2-effective-field-and-unitary

构造有效转轴与 SU(2) 演化算符

本步要点 (TL;DR)
  • 定义偏共振 $\delta = \omega_0 - \omega$ 与有效拉比频率 $\Omega_{\text{eff}} = \sqrt{\Omega^2 + \delta^2}$，把 $H_I$ 写成 $\Omega_{\text{eff}}\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}$。
  • 有效转轴 $\vec{\boldsymbol{n}} = (\sin\theta'\cos\varphi,\; \sin\theta'\sin\varphi,\; \cos\theta')$ 在共振（$\delta=0$）时倒在赤道 $x\text{-}y$ 平面内。
  • 引入泡利矩阵矢量 $\vec{\boldsymbol{\sigma}} = 2\vec{\boldsymbol{S}}$ 与转角 $\theta = \Omega_{\text{eff}}t$，演化算符成为 $U_I = \cos(\theta/2)\mathbb{1} - i\sin(\theta/2)\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}}$。

把失谐与驱动合成为单一有效场矢量

为了让常系数哈密顿量 $H_I = (\omega_0 - \omega)S_z + \Omega[\cos(\varphi)S_x + \sin(\varphi)S_y]$ 的几何意义一目了然，我们引入两个核心频率参数：驱动频率偏离能隙的程度称为偏共振（失谐） $\delta = \omega_0 - \omega$（对应《量子光学》第 4 章记号 $\Delta$），以及横向驱动与纵向失谐的矢量模长，称为有效拉比频率 $\Omega_{\text{eff}}$：

$$\delta = \omega_0 - \omega,\qquad \Omega_{\text{eff}} = \sqrt{\Omega^2 + \delta^2}$$

定义极角 $\theta'$ 满足 $\cos\theta' = \delta/\Omega_{\text{eff}}$、$\sin\theta' = \Omega/\Omega_{\text{eff}}$，于是单位有效转轴为 $\vec{\boldsymbol{n}} = (\sin\theta'\cos\varphi,\; \sin\theta'\sin\varphi,\; \cos\theta')$，整个有效哈密顿量缩并为标量与点乘的简洁形式：

$$H_I = \Omega_{\text{eff}}\,\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}$$

用泡利矩阵写出 $SU(2)$ 幺正演化算符

由于 $H_I$ 与时间无关，在旋转坐标系里从 $0$ 演化到 $t$ 的算符直接是矩阵指数 $U_I = e^{-i H_I t} = e^{-i\Omega_{\text{eff}} t\,\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}}$。引入泡利矩阵矢量 $\vec{\boldsymbol{\sigma}} = (\sigma_x, \sigma_y, \sigma_z) = 2\vec{\boldsymbol{S}}$，并记总旋转角 $\theta = \Omega_{\text{eff}} t$，由于 $(\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}})^2 = \mathbb{1}$，利用算符指数展开立即得到精确的 $SU(2)$ 演化算符：

$$U_I = e^{-i\frac{\theta}{2}\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}}} = \cos\left(\frac{\theta}{2}\right)\mathbb{1} - i\sin\left(\frac{\theta}{2}\right)\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}}$$

注意不要把有效转轴与 $z$ 轴的极角 $\theta'$（不随时间变），同绕有效轴转过的演化角度 $\theta = \Omega_{\text{eff}}t$（随时间线性增大）混为一谈。只有当共振 $\delta = 0$ 时 $\theta' = 90^\circ$，有效轴才完全躺在赤道面上，允许态矢绕水平轴彻底翻转到对极。

Worked Example

设某次磁共振驱动的参数为 $\Omega/(2\pi) = 6\text{ MHz}$，偏共振 $\delta/(2\pi) = 8\text{ MHz}$，驱动初相位 $\varphi = 0$，演化时长 $t = 25\text{ ns}$。

  1. 计算有效拉比频率 $\Omega_{\text{eff}}/(2\pi)$。 利用勾股关系合成本征有效频率：
    2. $$\Omega_{\text{eff}}/(2\pi) = \sqrt{6^2 + 8^2}\text{ MHz} = 10\text{ MHz}.$$
  1. 求出有效旋转轴单位矢量 $\vec{\boldsymbol{n}}$。 代入 $\sin\theta' = \Omega/\Omega_{\text{eff}} = 0.6$、$\cos\theta' = \delta/\Omega_{\text{eff}} = 0.8$ 与 $\varphi = 0$：
    2. $$\vec{\boldsymbol{n}} = (0.6,\; 0,\; 0.8).$$
  1. 算出演化角度 $\theta$ 并写出 $U_I$ 表达式。 先把普通频率 $10\text{ MHz}$ 换算为 $0.01\text{ ns}^{-1}$，再化为角频率乘以时间 $t = 25\text{ ns}$：
    2. $$\theta = (2\pi\times 0.01\text{ ns}^{-1})\times 25\text{ ns} = 2\pi \times 0.25 = \frac{\pi}{2},$$
    $$U_I = \cos(\pi/4)\mathbb{1} - i\sin(\pi/4)(0.6\sigma_x + 0.8\sigma_z) = \frac{1}{\sqrt{2}}\left[\mathbb{1} - i(0.6\sigma_x + 0.8\sigma_z)\right].$$

双路导出拉比跃迁概率公式

本步要点 (TL;DR)
  • 记 $|1\rangle \stackrel{\text{def}}{=} |m_S=-1/2\rangle \leftrightarrow |g\rangle$、$|0\rangle \stackrel{\text{def}}{=} |m_S=+1/2\rangle \leftrightarrow |e\rangle$，直接由 $U_I|1\rangle$ 读出上态振幅。
  • 拉比跃迁概率为 $P(t) = \frac{\Omega^2}{\Omega^2+\delta^2}\sin^2\left(\frac{\sqrt{\Omega^2+\delta^2}\,t}{2}\right)$（展开 $U_I|1\rangle$ 时须把 $n_z$ 留在 $\sin$ 项内）。
  • 《量子光学》用耦合概率幅二阶常微分方程导出完全一致的闭合概率公式。

路线一：用 $SU(2)$ 演化算符一步读出末态与概率

我们定义计算基 $|m_S = -1/2\rangle \stackrel{\text{def}}{=} |1\rangle$（下态，对应 $|g\rangle$）与 $|m_S = +1/2\rangle \stackrel{\text{def}}{=} |0\rangle$（上态，对应 $|e\rangle$）。在该基下，泡利矩阵的作用为 $\sigma_z|1\rangle = -|1\rangle$、$\sigma_x|1\rangle = |0\rangle$、$\sigma_y|1\rangle = -i|0\rangle$，从而 $(\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}})|1\rangle = -n_z|1\rangle + (n_x - i n_y)|0\rangle$。因为相互作用图像变换 $U_i = e^{-i\omega t S_z}$ 只给 $|1\rangle, |0\rangle$ 乘上对角纯相位（且 $U_i(0)=\mathbb{1}$），旋转系内的跃迁振幅模方与实验室系完全一致。若初态为 $|1\rangle$，直接作用演化算符 $U_I$ 即得：

$$|\psi(t)\rangle = U_I|1\rangle = \left(\cos\frac{\theta}{2} + i\sin\frac{\theta}{2}\, n_z\right)|1\rangle + \left(-i\sin\frac{\theta}{2}\right)(n_x - i n_y)|0\rangle$$

（注：切勿把前项括号误作 $(\cos\frac{\theta}{2}+i\sin\frac{\theta}{2})n_z$，由 $\mathbb{1}|1\rangle=|1\rangle$ 可见 $n_z$ 仅乘在 $\sin\frac{\theta}{2}$ 上。）取出 $|0\rangle$ 态振幅取模平方，利用 $n_x^2 + n_y^2 = \sin^2\theta' = \Omega^2/\Omega_{\text{eff}}^2$ 与 $\theta = \Omega_{\text{eff}}t$，立即导出拉比跃迁概率：

$$P(t) = |\langle 0|\psi(t)\rangle|^2 = \frac{\Omega^2}{\Omega^2 + \delta^2}\sin^2\left(\frac{\sqrt{\Omega^2 + \delta^2}\,t}{2}\right)$$

路线二：《量子光学》耦合概率幅微分方程验证

对照《量子光学》耦合概率幅写法：展开 $|\psi(t)\rangle = C_g(t)e^{-i E_g t/\hbar}|g\rangle + C_e(t)e^{-i E_e t/\hbar}|e\rangle$ 代入薛定谔方程，在 RWA 与 $\Omega = V/\hbar$、$\delta = \omega_0 - \omega$ 下得到一阶耦合方程 $\dot{C}_g = -\frac{i\Omega}{2}e^{-i\delta t}C_e$、$\dot{C}_e = -\frac{i\Omega}{2}e^{i\delta t}C_g$。消去 $C_g$ 化为二阶常系数方程 $\ddot{C}_e - i\delta\dot{C}_e + \frac{\Omega^2}{4}C_e = 0$，代入振荡试探解 $C_e(t)\propto e^{i\lambda t}$ 得特征根 $\lambda_\pm = \frac{1}{2}(\delta \pm \Omega_{\text{eff}})$，配合初值 $C_g(0)=1, C_e(0)=0$ 解出 $|C_e(t)|^2$，结果与上式 $P(t)$ 严丝合缝！

注意偏共振 $|\delta|$ 的双重作用：失谐越大，振幅系数 $\Omega^2/(\Omega^2+\delta^2)$ 降得越低（永远无法 $100\%$ 反转）；但同时有效频率 $\Omega_{\text{eff}}$ 变大，使振荡周期缩短、频率变快！

Worked Example

继续沿用刚才的参数：驱动强度 $\Omega/(2\pi) = 6\text{ MHz}$，偏共振 $\delta/(2\pi) = 8\text{ MHz}$，于是 $\Omega_{\text{eff}}/(2\pi) = 10\text{ MHz}$。设初态为 $|1\rangle$，演化时间 $t = 25\text{ ns}$（对应 $\theta = \pi/2$）。

  1. 利用 $\vec{\boldsymbol{n}} = (0.6, 0, 0.8)$ 与 $\theta = \pi/2$ 写出归一化末态 $|\psi\rangle$。
    2. $$|\psi\rangle = \frac{1}{\sqrt{2}}(1 + 0.8i)|1\rangle - \frac{0.6i}{\sqrt{2}}|0\rangle.$$
  1. 核对归一化与 $|0\rangle$ 态跃迁概率。
    2. $$|\langle 0|\psi\rangle|^2 = \left(\frac{0.6}{\sqrt{2}}\right)^2 = 0.18,\qquad P_{\max} = \frac{6^2}{6^2+8^2} = 0.36.$$

验证 $|\langle 1|\psi\rangle|^2 + |\langle 0|\psi\rangle|^2 = \frac{1+0.64}{2} + 0.18 = 0.82 + 0.18 = 1$，而且用拉比公式 $\frac{6^2}{10^2}\sin^2(\pi/4) = 0.36 \times 0.5 = 0.18$，与微分方程解 $|C_e(t)|^2$ 完全吻合。

分析粒子数反转、共振脉冲与量子化拉比振荡

本步要点 (TL;DR)
  • 粒子数反转定义为 $W(t) = P_e(t) - P_g(t) = 2P(t) - 1$，共振（$\delta=0$）时从 $|1\rangle$ 出发有 $W(t) = -\cos(\Omega t)$。
  • 当 $\Omega t = \pi$ 称作 $\pi$ 脉冲（$P=1, W=+1$ 完全反转）；当 $\Omega t = \pi/2$ 称作 $\pi/2$ 脉冲（$P=0.5, W=0$ 等权叠加）。
  • 在全量子 Jaynes–Cummings 模型中，$n$ 光子数态给出量子化拉比频率 $\Omega(n) = 2\lambda\sqrt{n+1}$，即使真空 $n=0$ 仍发生真空拉比振荡。

粒子数反转 $W(t)$ 与共振 $\pi$ / $(\pi/2)$ 脉冲

在实验与《量子光学》第 4.4 节（式 4.84–4.87）中，除了直接看上态布居 $P_e(t)$，还常使用上、下能级布居之差——粒子数反转（atomic/population inversion）：

$$W(t) = P_e(t) - P_g(t) = 2P(t) - 1$$

范围从 $-1$（全在下态 $|g\rangle\equiv|1\rangle$）到 $+1$（全在上态 $|e\rangle\equiv|0\rangle$）。当严格共振（$\delta = 0$，有效场落在赤道面）且初态处于下态 $|1\rangle$ 时，$P(t) = \sin^2(\Omega t/2)$，对应 $W(t) = -\cos(\Omega t)$。此时两个最关键的脉冲时长决定了基础量子操作：

  • $\pi$ 脉冲：控制时长 $t_\pi = \pi/\Omega$ 使转角 $\theta = \Omega t_\pi = \pi$，得 $P = 1$、$W = +1$，把态完整翻转到 $|0\rangle$（忽略整体相位）；
  • $\pi/2$ 脉冲：取半个时长 $t_{\pi/2} = \pi/(2\Omega)$ 使 $\theta = \pi/2$，得 $P = 0.5$、$W = 0$，从 $|1\rangle$ 出发制出等概率相干叠加态 $\frac{1}{\sqrt{2}}(|1\rangle - i e^{-i\varphi}|0\rangle)$（当选用相反电偶极/相位约定如 $\varphi=\pi$ 时对应《量子光学》记法中的等权叠加态 $\frac{1}{\sqrt{2}}(|g\rangle + i|e\rangle)$，具体单比特量子门参数化会在第 2 单元深入展开）。

推广至全量子 Jaynes–Cummings 模型的拉比振荡

如果把经典驱动场换成单模量子谐振腔光场（初态有 $n$ 个光子，原子处于激发态 $|e\rangle|n\rangle$），在上一课推导的 JC 哈密顿量 $\hat{H}_{\text{JC}}/\hbar = \frac{1}{2}\omega_0\hat{\sigma}_3 + \omega a^\dagger a + \lambda(\hat{\sigma}_+ a + \hat{\sigma}_- a^\dagger)$ 中，激发数算符 $N_e = a^\dagger a + |e\rangle\langle e|$ 守恒，因此仅耦合 $|e\rangle|n\rangle$ 与 $|g\rangle|n+1\rangle$ 这两个态！对照旋转坐标系中共振驱动 $H_I|_{\delta=0,\varphi=0} = \Omega S_x = \frac{\Omega}{2}(S^+ + S^-)$ 的升降跃迁矩阵元恰好为 $\Omega/2$，而在 JC 模型里由 $a^\dagger|n\rangle = \sqrt{n+1}|n+1\rangle$ 得到的耦合非对角元恰好等于 $\lambda\sqrt{n+1}$（精准扮演半经典中 $\Omega/2$ 的角色）。由于此处初态取原子在上态 $|e\rangle|n\rangle$（上态布居 $P_e = 1 - P_{|e,n\rangle\to|g,n+1\rangle}$），反转度相对下态初态差一个负号，因此共振跃迁概率与量子电动力学拉比频率 $\Omega(n)$ 为（式 4.114–4.116）：

$$\Omega(n) = 2\lambda\sqrt{n+1},\qquad P_{|e,n\rangle \to |g,n+1\rangle}(t) = \sin^2\left(\lambda\sqrt{n+1}\,t\right),\qquad W(t) = \cos[\Omega(n)t]$$

最惊人的推论在 $n = 0$：即便光腔里一颗光子也没有（零光子真空态 $|n=0\rangle$），只要 $\lambda \ne 0$，依然存在 $\Omega(0) = 2\lambda$ 的真空拉比振荡——原子可逆地放出并重新吸收同一颗光子，彻底超越半经典模型！

从跃迁概率曲线走向可编程量子逻辑门

在 Unit 1 最后一课，我们利用演化算符 $U_I$ 计算了上下能级之间的跃迁概率。本课把视角切换为量子门设计：不再只关心终态布居数，而是把 $U_I$ 本身作为作用于计算基 $|0\rangle = (1,0)^T$、$|1\rangle = (0,1)^T$ 的单比特幺正门。

共振赤道面脉冲门：相控 X/Y 旋转

本步要点 (TL;DR)
  • 共振条件 $\delta = 0$ 使极角 $\alpha = \pi/2$，有效转轴 $\vec{\boldsymbol{n}} = (\cos\beta, \sin\beta, 0)$ 落在赤道平面，转角 $\theta = \Omega t$。
  • 代入一般旋转公式即得 $(\pi/2)_\beta$ 与 $(\pi)_\beta$：令 $\beta=0$ 对应 $x$ 轴门，令 $\beta=\pi/2$ 对应 $y$ 轴门。
  • 磁共振中 $(\pi)_x = -i\sigma_x$、$(\pi)_y = -i\sigma_y$（注：原讲义第 7 页将 $\beta=0$ 的矩阵误印为 $(\pi)_\pi$，实为 $(\pi)_x$）。

从一般有效转轴到共振赤道平面

在《磁共振基础》第 1.3 节中（对应上单元记号 $\varphi \mapsto \beta$、$\theta' \mapsto \alpha$），旋转坐标系内任意常参脉冲的演化算符记为式 (1.33)：

$$U = e^{-i\theta\,\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}} = \cos\left(\frac{\theta}{2}\right)\mathbb{1} - i\sin\left(\frac{\theta}{2}\right)\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}}$$

其中有效转角 $\theta = \Omega_{\text{eff}}t$，有效拉比频率 $\Omega_{\text{eff}} = \sqrt{\Omega^2 + \delta^2}$，转轴 $\vec{\boldsymbol{n}} = (\sin\alpha\cos\beta,\; \sin\alpha\sin\beta,\; \cos\alpha)$ 满足 $\cos\alpha = \delta/\Omega_{\text{eff}}$，$\beta$ 为驱动微波或激光的初始相位。

当满足精确共振 $\delta = \omega_0 - \omega = 0$ 时，有 $\Omega_{\text{eff}} = \Omega$、$\cos\alpha = 0$（即 $\alpha = \pi/2$），因此转角简化为 $\theta = \Omega t$，而有效转轴完全躺在 $x\text{-}y$ 赤道平面内：

$$\vec{\boldsymbol{n}} = (\cos\beta,\; \sin\beta,\; 0),\qquad \vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}} = \cos\beta\,\sigma_x + \sin\beta\,\sigma_y = \begin{pmatrix}0 & e^{-i\beta}\\ e^{i\beta} & 0\end{pmatrix}.$$

$(\pi/2)_\beta$、$(\pi)_\beta$ 与 Pauli-X/Y 门家族

将上式代回 $U$ 的矩阵展开式，立刻得到由驱动相位 $\beta$ 连续调控的两类核心赤道脉冲门：

$$\left(\frac{\pi}{2}\right)_\beta = \frac{1}{\sqrt{2}}\begin{pmatrix}1 & -i e^{-i\beta}\\ -i e^{i\beta} & 1\end{pmatrix},\qquad (\pi)_\beta = \begin{pmatrix}0 & -i e^{-i\beta}\\ -i e^{i\beta} & 0\end{pmatrix}.$$

分别取驱动相位 $\beta = 0$（$x$ 轴）与 $\beta = \pi/2$（$y$ 轴，此时 $e^{\pm i\pi/2} = \pm i$），即得实验最常用的四个基本门：

$$\left(\frac{\pi}{2}\right)_x = \frac{1}{\sqrt{2}}\begin{pmatrix}1 & -i\\ -i & 1\end{pmatrix},\qquad \left(\frac{\pi}{2}\right)_y = \frac{1}{\sqrt{2}}\begin{pmatrix}1 & -1\\ 1 & 1\end{pmatrix}$$

$$(\pi)_x = \begin{pmatrix}0 & -i\\ -i & 0\end{pmatrix} = -i\sigma_x,\qquad (\pi)_y = \begin{pmatrix}0 & -1\\ 1 & 0\end{pmatrix} = -i\sigma_y.$$

需要特别留意一处教材勘误：原讲义第 7 页将 $\beta = 0$、$\theta = \pi$ 对应的矩阵错印成 $(\pi)_\pi$，按轴下标规则该处应为 $(\pi)_x$（代表物理 Pauli-X 翻转门，相对纯泡利矩阵 $\sigma_x$ 多一个 $-i$ 因子）。同理，$(\pi)_y$ 对应物理 Pauli-Y 门。

Worked Example

设自旋在精确共振下（$\delta = 0$）受到拉比频率为 $\Omega/(2\pi) = 10\text{ MHz}$ 的横向驱动脉冲作用。

  1. 求 $\pi/2$ 脉冲与 $\pi$ 脉冲的持续时间。

共振时 $\theta = \Omega t$，因此

$$t_{\pi/2} = \frac{\pi/2}{\Omega} = \frac{1}{4(\Omega/2\pi)} = \frac{1}{40\text{ MHz}} = 25\text{ ns},\qquad t_\pi = \frac{\pi}{\Omega} = 50\text{ ns}.$$

  1. 计算初态 $|1\rangle = (0, 1)^T$ 经 $(\pi/2)_y$（$t = 25\text{ ns}, \beta = \pi/2$）后的末态。
    2. $$\left(\frac{\pi}{2}\right)_y |1\rangle = \frac{1}{\sqrt{2}}\begin{pmatrix}1 & -1\\ 1 & 1\end{pmatrix}\begin{pmatrix}0\\ 1\end{pmatrix} = \frac{1}{\sqrt{2}}\begin{pmatrix}-1\\ 1\end{pmatrix} = \frac{1}{\sqrt{2}}\left(-|0\rangle + |1\rangle\right).$$

两基矢 $|0\rangle$ 与 $|1\rangle$ 的测量概率均为 $|\pm 1/\sqrt{2}|^2 = 1/2$，且形成实系数等权叠加。

  1. 计算初态 $|1\rangle$ 经 $(\pi)_x$（$t = 50\text{ ns}, \beta = 0$）后的末态。
    2. $$(\pi)_x |1\rangle = \begin{pmatrix}0 & -i\\ -i & 0\end{pmatrix}\begin{pmatrix}0\\ 1\end{pmatrix} = \begin{pmatrix}-i\\ 0\end{pmatrix} = -i|0\rangle,$$

实现了自旋从 $|1\rangle$ 到 $|0\rangle$ 的完全比特翻转（仅带整体相位 $-i$）。

第 4 课 Step 2 · gate-z-and-hadamard-pulses

自由演化 z 相位门与倾斜轴 Hadamard 门

本步要点 (TL;DR)
  • 关闭驱动（$\Omega=0$）时转轴竖直朝 $+z$，演化角 $\theta = \delta t$ 产生对角相移门 $T$（$\pi/4$）、$S$（$\pi/2$）与 $Z_{\text{MR}} = -i\sigma_z$（$\pi$）。
  • 令驱动与失谐相等（$\Omega = \delta$）且相位 $\beta = 0$，有效拉比频率增大至 $\Omega_{\text{eff}} = \sqrt{2}\Omega$，转轴倾角为 $45^\circ$。
  • 持续作用 $\theta = \sqrt{2}\Omega t = \pi$ 即实现磁共振 Hadamard 门 $H_{\text{MR}} = -i(\sigma_x+\sigma_z)/\sqrt{2}$。

零驱动失谐自由演化：$T$、$S$ 与 $Z_{\text{MR}}$ 相位门

若完全关闭横向驱动场（$\Omega = 0$）而保留频率失谐 $\delta > 0$，则 $\Omega_{\text{eff}} = \delta$、$\cos\alpha = 1$（$\alpha = 0$），有效转轴直指 $+z$ 方向：$\vec{\boldsymbol{n}} = (0, 0, 1)$。此时演化算符成为纯对角相移矩阵：

$$U|_{\Omega=0} = e^{-i\delta t S_z} = \cos\left(\frac{\delta t}{2}\right)\mathbb{1} - i\sin\left(\frac{\delta t}{2}\right)\sigma_z = \begin{pmatrix}e^{-i\delta t/2} & 0\\ 0 & e^{i\delta t/2}\end{pmatrix}.$$

调节自由演化时间使积累相位 $\theta = \delta t$ 分别取 $\pi/4$、$\pi/2$ 与 $\pi$，便无须额外驱动脉冲而直接获得三类标准 $z$ 旋转门：

$$T_{\text{MR}} = \begin{pmatrix}e^{-i\pi/8} & 0\\ 0 & e^{i\pi/8}\end{pmatrix},\qquad S_{\text{MR}} = \begin{pmatrix}e^{-i\pi/4} & 0\\ 0 & e^{i\pi/4}\end{pmatrix},\qquad Z_{\text{MR}} = \begin{pmatrix}-i & 0\\ 0 & i\end{pmatrix} = -i\sigma_z.$$

它们依次对应量子电路中的 $\pi/8$ 门（$T$ 门）、相位门（$S$ 门）与磁共振 Pauli-Z 门。

倾斜有效轴（$\Omega=\delta, \beta=0$）合成 Hadamard 门

为了把 $|0\rangle$ 与 $|1\rangle$ 对称地旋转到彼此的等权叠加态，只需同时打开横向驱动与纵向失谐：令 $\Omega = \delta > 0$ 且取驱动相位 $\beta = 0$。此时有效拉比频率 $\Omega_{\text{eff}} = \sqrt{\Omega^2 + \delta^2} = \sqrt{2}\Omega$，转轴极角满足 $\cos\alpha = \sin\alpha = 1/\sqrt{2}$（$\alpha = 45^\circ$），因此单位转轴精确指向 $x\text{-}z$ 平面 $45^\circ$ 角平分线：

$$\vec{\boldsymbol{n}} = \left(\frac{1}{\sqrt{2}},\; 0,\; \frac{1}{\sqrt{2}}\right),\qquad \vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}} = \frac{\sigma_x + \sigma_z}{\sqrt{2}} = \frac{1}{\sqrt{2}}\begin{pmatrix}1 & 1\\ 1 & -1\end{pmatrix}.$$

控制脉宽使总转角 $\theta = \Omega_{\text{eff}}t = \sqrt{2}\Omega t = \pi$，由于 $\cos(\pi/2) = 0$、$\sin(\pi/2) = 1$，立刻得到磁共振物理实现的 Hadamard 门：

$$H_{\text{MR}} = -i\,\frac{\sigma_x + \sigma_z}{\sqrt{2}} = -\frac{i}{\sqrt{2}}\begin{pmatrix}1 & 1\\ 1 & -1\end{pmatrix}.$$

与标准 Hadamard 矩阵 $\frac{1}{\sqrt{2}}\begin{pmatrix}1 & 1\\ 1 & -1\end{pmatrix}$ 相比，$H_{\text{MR}}$ 仅相差全局相位因子 $-i$。把两者的计算基作用同共振 $(\pi/2)_y$ 门对比可见：$(\pi/2)_y$ 将 $|0\rangle \to \frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)$、$|1\rangle \to \frac{1}{\sqrt{2}}(-|0\rangle+|1\rangle)$，且平方 $(\pi/2)_y^2 = (\pi)_y$ 翻转基态；而 $H_{\text{MR}}$ 分别给出 $H_{\text{MR}}|0\rangle = -\frac{i}{\sqrt{2}}(|0\rangle+|1\rangle)$ 与 $H_{\text{MR}}|1\rangle = -\frac{i}{\sqrt{2}}(|0\rangle-|1\rangle)$（即 $H_{\text{MR}}|0\rangle = -i(\pi/2)_y|0\rangle$，而 $H_{\text{MR}}|1\rangle = +i(\pi/2)_y|1\rangle$），且平方满足 $H_{\text{MR}}^2 = -\mathbb{1}$。

Worked Example

某电子自旋量子比特实验设定驱动拉比频率为 $\Omega/(2\pi) = 5\text{ MHz}$。

  1. 求单脉冲实现 Hadamard 门 $H_{\text{MR}}$ 所需的失谐与脉宽 $t_H$。

取 $\delta/(2\pi) = \Omega/(2\pi) = 5\text{ MHz}$ 且相位 $\beta = 0$，有效拉比频率提高至

$$\frac{\Omega_{\text{eff}}}{2\pi} = \sqrt{5^2 + 5^2} = 5\sqrt{2}\text{ MHz}.$$

令 $\theta = \Omega_{\text{eff}}t_H = \pi$，所需脉宽为

$$t_H = \frac{\pi}{\Omega_{\text{eff}}} = \frac{1}{2 \cdot 5\sqrt{2}\text{ MHz}} = \frac{100}{\sqrt{2}}\text{ ns} \approx 70.71\text{ ns}.$$

  1. 对比同一失谐 $\delta/(2\pi) = 5\text{ MHz}$ 下自由演化（$\Omega = 0$）实现 $S_{\text{MR}}$ 与 $T_{\text{MR}}$ 门的时间。

在 $\Omega = 0$ 时 $\theta = \delta t$，故

$$t_S = \frac{\pi/2}{\delta} = \frac{1}{4 \cdot 5\text{ MHz}} = 50\text{ ns},\qquad t_T = \frac{\pi/4}{\delta} = \frac{1}{8 \cdot 5\text{ MHz}} = 25\text{ ns}.$$

SU(2) 全局相位差异与任意单比特门合成

本步要点 (TL;DR)
  • 物理脉冲演化属于 $SU(2)$ 群，恒满足 $U^\dagger U = \mathbb{1}$ 且 $\det(U) = +1$；计算机门约定通常归入 $U(2)$（如 $\det(\hat{U}_{\text{H}}) = -1$）。
  • 全局相位因子 $e^{i\gamma}$ 不改变单比特测量概率与基矢相对相位，因此 $H_{\text{MR}} = -i\hat{U}_{\text{H}}$ 在单比特意义下完全等价，尽管 $H_{\text{MR}}^2 = -\mathbb{1}$。
  • 四门电路 $\hat{U}_{\text{PG}}(\varphi+\pi/2)\hat{U}_{\text{H}}\hat{U}_{\text{PG}}(2\theta)\hat{U}_{\text{H}}|0\rangle$ 精准输出任意叠加态（含全局相位 $e^{i\theta}$）。

物理 $SU(2)$ 脉冲门与计算 $U(2)$ 门约定对比

对比第 1、2 知识点的脉冲矩阵与《Introductory Quantum Optics》§11.10 式 (11.27)–(11.28) 定义的计算量子门，会发现两者总是相差一个复相位因子：

$$\hat{U}_{\text{H}} = \frac{1}{\sqrt{2}}\begin{pmatrix}1 & 1\\ 1 & -1\end{pmatrix} \implies H_{\text{MR}} = -i\,\hat{U}_{\text{H}},$$

$$\hat{U}_{\text{PG}}(\varphi) = \begin{pmatrix}1 & 0\\ 0 & e^{i\varphi}\end{pmatrix} = e^{i\varphi/2} e^{-i\varphi S_z} \implies \hat{U}_{\text{PG}}\!\left(\frac{\pi}{4}\right) = e^{i\pi/8}T_{\text{MR}},\quad \hat{U}_{\text{PG}}\!\left(\frac{\pi}{2}\right) = e^{i\pi/4}S_{\text{MR}},\quad \hat{U}_{\text{PG}}(\pi) = i Z_{\text{MR}}.$$

这一系统性差异根源于群论约束：所有由 $e^{-i\theta\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}}$ 生成的物理脉冲门都满足幺正性 $U^\dagger U = \mathbb{1}$ 与单位行列式 $\det(U) = +1$，属于特殊幺正群 $SU(2)$——直接验算即知 $\det(H_{\text{MR}}) = (-i/\sqrt{2})^2(-1-1) = +1$、$\det(Z_{\text{MR}}) = (-i)(i) = +1$。相反，教科书计算门为了把矩阵元简化为实数或让 $|0\rangle$ 分量取 $1$，放弃了 $\det = 1$ 而落在一般幺正群 $U(2)$ 中：例如 $\det(\hat{U}_{\text{H}}) = -1$、$\det(\hat{U}_{\text{PG}}(\varphi)) = e^{i\varphi}$。

全局相位不可观测性与四门任意态合成电路

对任意单比特末态 $|\psi'\rangle = e^{i\gamma}(c_0|0\rangle + c_1|1\rangle)$，全局相位 $e^{i\gamma}$ 不具备物理可观测量：测量 $|0\rangle$、$|1\rangle$ 的概率为 $|e^{i\gamma}c_k|^2 = |c_k|^2$，两分量之间的相对相位比 $(e^{i\gamma}c_1)/(e^{i\gamma}c_0) = c_1/c_0$ 也完全消去 $e^{i\gamma}$。但作平方运算时须留神：$H_{\text{MR}}^2 = (-i)^2 \hat{U}_{\text{H}}^2 = -\mathbb{1}$，而 $\hat{U}_{\text{H}}^2 = +\mathbb{1}$（这一 $-1$ 符号正是自旋 $1/2$ 旋转 $2\pi$ 的特征整体相位）。

利用 $\hat{U}_{\text{H}}$ 门与相位门 $\hat{U}_{\text{PG}}$ 的交替级联，可将任意单比特叠加态合成为四步通用电路（《量子光学》式 11.29）：

$$\hat{U}_{\text{PG}}\!\left(\varphi + \frac{\pi}{2}\right)\,\hat{U}_{\text{H}}\,\hat{U}_{\text{PG}}(2\theta)\,\hat{U}_{\text{H}}|0\rangle = e^{i\theta}\left(\cos\theta\,|0\rangle + e^{i\varphi}\sin\theta\,|1\rangle\right).$$

一般参数 $(\theta,\varphi)$ 下的三步矩阵推导十分直接：先由 $\hat{U}_{\text{H}}|0\rangle = \frac{1}{\sqrt{2}}(|0\rangle+|1\rangle)$，再经 $\hat{U}_{\text{PG}}(2\theta)$ 并提取公共相位 $e^{i\theta}$ 得 $e^{i\theta}\frac{1}{\sqrt{2}}(e^{-i\theta}|0\rangle + e^{i\theta}|1\rangle)$；随后第二次 $\hat{U}_{\text{H}}$ 借助欧拉公式 $\frac{e^{-i\theta}\pm e^{i\theta}}{2}$ 将其化为 $e^{i\theta}(\cos\theta\,|0\rangle - i\sin\theta\,|1\rangle)$，最后 $\hat{U}_{\text{PG}}(\varphi+\pi/2)$ 将 $-i = e^{-i\pi/2}$ 调相为 $e^{i\varphi}$。严格矩阵乘法给出前方的整体因子 $e^{i\theta}$；Gerry 与 Knight 在式 (11.29) 中略去了该不可观测全局相位，两者表示同一个单比特物理量子态。

Worked Example

  1. 验证 $H_{\text{MR}}^2$ 与 $\hat{U}_{\text{H}}^2$ 的全局相位差异。
    2. $$H_{\text{MR}}^2 = \left[-\frac{i}{\sqrt{2}}\begin{pmatrix}1 & 1\\ 1 & -1\end{pmatrix}\right]^2 = -\frac{1}{2}\begin{pmatrix}2 & 0\\ 0 & 2\end{pmatrix} = -\mathbb{1},\qquad \hat{U}_{\text{H}}^2 = +\mathbb{1}.$$

物理上两次 Hadamard 脉冲等效于绕倾斜轴 $\vec{\boldsymbol{n}}$ 旋转 $2\pi$，给出标志性的自旋半整数整体负号 $-\mathbb{1}$。

  1. 逐步追踪 $\theta = \pi/6$、$\varphi = \pi/2$ 时的 Gerry–Knight 四门合成电路。

初态取 $|0\rangle = (1, 0)^T$：

  • 第一步 $\hat{U}_{\text{H}}|0\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$；
  • 第二步施加 $\hat{U}_{\text{PG}}(2\theta) = \hat{U}_{\text{PG}}(\pi/3)$，提公因子 $e^{i\pi/6}$：

$$\frac{1}{\sqrt{2}}\left(|0\rangle + e^{i\pi/3}|1\rangle\right) = e^{i\pi/6}\,\frac{1}{\sqrt{2}}\left(e^{-i\pi/6}|0\rangle + e^{i\pi/6}|1\rangle\right);$$

  • 第三步再施加 $\hat{U}_{\text{H}}$：利用 $\frac{e^{-i\pi/6}+e^{i\pi/6}}{2} = \cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}$ 与 $\frac{e^{-i\pi/6}-e^{i\pi/6}}{2} = -i\sin\frac{\pi}{6} = -\frac{i}{2}$，得到

$$e^{i\pi/6}\left(\frac{\sqrt{3}}{2}|0\rangle - \frac{i}{2}|1\rangle\right);$$

  • 第四步施加 $\hat{U}_{\text{PG}}(\varphi + \pi/2) = \hat{U}_{\text{PG}}(\pi) = \text{diag}(1, -1)$，把 $|1\rangle$ 前的负号翻正：

$$e^{i\pi/6}\left(\frac{\sqrt{3}}{2}|0\rangle + \frac{i}{2}|1\rangle\right) = e^{i\pi/6}\left(\cos\frac{\pi}{6}|0\rangle + e^{i\pi/2}\sin\frac{\pi}{6}|1\rangle\right).$$

略去整体相位 $e^{i\pi/6}$ 即匹配式 (11.29) 的目标叠加态，且布居概率为 $P_0 = 3/4$、$P_1 = 1/4$。

建立单比特纯态与 Bloch 球面的几何映射

本步要点 (TL;DR)
  • 任意单比特纯态 $|\psi\rangle = \cos(\theta/2)|0\rangle + \sin(\theta/2)e^{i\varphi}|1\rangle$ 对应单位 Bloch 矢量 $\vec{\boldsymbol{n}} = (\sin\theta\cos\varphi, \sin\theta\sin\varphi, \cos\theta)$（$|\vec{\boldsymbol{n}}|=1$）。

  • Bloch 球上的对跖点 $+\vec{\boldsymbol{n}}$ 与 $-\vec{\boldsymbol{n}}$ 对应相互正交的纯态。

消去整体相位：从纯态态矢到投影密度矩阵

取计算基 $|0\rangle = |m_S=+1/2\rangle = (1,0)^T$ 与 $|1\rangle = |m_S=-1/2\rangle = (0,1)^T$，任意归一化单比特纯态（相差整体相位视为同一物理态）均可按式 (1.34) 参数化为：

$$|\psi\rangle = \cos\left(\frac{\theta}{2}\right)|0\rangle + \sin\left(\frac{\theta}{2}\right)e^{i\varphi}|1\rangle,\qquad \theta\in[0,\pi],\;\varphi\in[0,2\pi)$$

在 Gerry–Knight《Introductory Quantum Optics》附录 A 式 (A26) 中，作者采用对称相位写法 $|\Psi\rangle = \cos(\frac{\theta}{2})e^{-i\varphi/2}|0\rangle + \sin(\frac{\theta}{2})e^{i\varphi/2}|1\rangle = e^{-i\varphi/2}|\psi\rangle$。只要构造密度矩阵（投影算符） $\rho = |\psi\rangle\langle\psi|$，整体相位因子便因 $e^{-i\varphi/2}e^{+i\varphi/2} = 1$ 而彻底消去，两种写法给出完全相同的 $\rho$！

展开密度矩阵与矩阵元符号核对

由 $\vec{\boldsymbol{\sigma}} = 2\vec{\boldsymbol{S}}$ 可知泡利矩阵为 $\sigma_x = \begin{pmatrix}0&1\\1&0\end{pmatrix}$、$\sigma_y = \begin{pmatrix}0&-i\\i&0\end{pmatrix}$、$\sigma_z = \begin{pmatrix}1&0\\0&-1\end{pmatrix}$。利用 $|0\rangle\langle 0| = \frac{\mathbb{1}+\sigma_z}{2}$、$|1\rangle\langle 1| = \frac{\mathbb{1}-\sigma_z}{2}$ 以及 $e^{-i\varphi}|0\rangle\langle 1| + e^{i\varphi}|1\rangle\langle 0| = \cos\varphi\,\sigma_x + \sin\varphi\,\sigma_y$，结合倍角公式即可导出式 (1.35)：

$$\rho = |\psi\rangle\langle\psi| = \frac{\mathbb{1} + \vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}}}{2} = \frac{1}{2}\begin{pmatrix} 1+n_z & n_x - i n_y \\ n_x + i n_y & 1-n_z \end{pmatrix}$$

其中单位 Bloch 矢量 $\vec{\boldsymbol{n}} = (\sin\theta\cos\varphi,\; \sin\theta\sin\varphi,\; \cos\theta)$ 满足 $|\vec{\boldsymbol{n}}|=1$，所有纯态恰好铺满单位球面。特别警示：Gerry–Knight 附录 A 式 (A25) 虽在式 (A24) 取标准 $\sigma_2 = \sigma_y = \begin{pmatrix}0&-i\\i&0\end{pmatrix}$，却误把矩阵右上角与左下角的 $\pm i s_2$ 符号写反；请务必以匹配的 $\rho_{01} = \frac{1}{2}(n_x - i n_y)$ 与 $\rho_{10} = \frac{1}{2}(n_x + i n_y)$ 为准！

注意几何夹角与希尔伯特空间正交性的联系：取对跖矢量 $\pm\vec{\boldsymbol{n}}$（球面上相距 $180^\circ$），在极角与方位角上对应 $(\theta,\varphi)$ 与 $(\pi-\theta,\varphi+\pi)$，两态满足 $\langle\psi_+|\psi_-\rangle = 0$（等价地 $\operatorname{Tr}(\rho_+\rho_-) = \frac{1}{4}\operatorname{Tr}(\mathbb{1} - (\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}})^2) = 0$）。例如北极 $|0\rangle$ 与南极 $|1\rangle$ 正交，赤道 $+x$ 态 $|+x\rangle = \frac{|0\rangle+|1\rangle}{\sqrt{2}}$ 与 $-x$ 态正交。

刻画混态密度矩阵、迹反演与纯度判据

本步要点 (TL;DR)

  • 纯度 $\operatorname{Tr}(\rho^2) = \frac{1+|\vec{\boldsymbol{n}}|^2}{2}$ 满足纯态 $=1$、混态 $<1$；$\rho$ 的本征值为 $\lambda_\pm = \frac{1\pm|\vec{\boldsymbol{n}}|}{2}$。

系综混合态与讲义式 (1.36) 的笔误修正

当系统以经典概率 $p_k \ge 0$（$\sum_k p_k = 1$）处于不同纯态 $|\psi_k\rangle$ 时，密度矩阵为投影算符的加权和（Gerry–Knight 附录 A 式 A4）：$\rho = \sum_k p_k |\psi_k\rangle\langle\psi_k|$。注意磁共振讲义式 (1.36) 误印成了 $|\psi_1\rangle\langle\varphi_1|$：构造投影算符时右矢与左矢必须取同一量子态，正确写法应为 $p_1|\psi_1\rangle\langle\psi_1| + p_2|\psi_2\rangle\langle\psi_2|$！代入式 (1.35) 立即得：

$$\rho = \frac{\mathbb{1} + \vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}}}{2},\qquad \vec{\boldsymbol{n}} = \sum_k p_k\vec{\boldsymbol{n}}_k,\qquad |\vec{\boldsymbol{n}}| \le \sum_k p_k|\vec{\boldsymbol{n}}_k| = 1$$

这正是式 (1.37)：纯态落在单位球面（$|\vec{\boldsymbol{n}}|=1$），不同纯态（或非同向纯态）的混合使矢量缩入球体内部（$|\vec{\boldsymbol{n}}|<1$），等权混合正交态退缩到球心 $\vec{\boldsymbol{n}}=\vec{\boldsymbol{0}}$（$\rho = \mathbb{1}/2$，完全失去非对角相干元）。

迹反演公式与式 (1.38) 的 /2 勘误

从已知 $\rho$ 反推 $\vec{\boldsymbol{n}}$ 需利用泡利乘积恒等式 $\sigma_i\sigma_j = \delta_{ij}\mathbb{1} + i\epsilon_{ijk}\sigma_k$ 及 $\operatorname{Tr}(\sigma_k)=0$、$\operatorname{Tr}(\mathbb{1})=2$：

$$\operatorname{Tr}(\rho\sigma_j) = \frac{1}{2}\operatorname{Tr}(\sigma_j) + \frac{1}{2}\sum_i n_i\operatorname{Tr}(\delta_{ij}\mathbb{1} + i\epsilon_{ijk}\sigma_k) = \frac{1}{2}\sum_i n_i(2\delta_{ij}) = n_j \implies \vec{\boldsymbol{n}} = \operatorname{Tr}(\rho\vec{\boldsymbol{\sigma}})$$

这里必须明确修正讲义式 (1.38) 的第二处印刷笔误：讲义漏掉了括号外由 $\rho = \frac{\mathbb{1}+\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}}}{2}$ 带来的因子 $1/2$，却误把 /2 塞进泡利乘积写成了 $\delta_{ij}\mathbb{1} + i\epsilon_{ijk}\sigma_k/2$！实际上 $\sigma_i\sigma_j$ 内绝对没有 /2（如 $\sigma_x\sigma_y = i\sigma_z$），系数 $1/2$ 始终位于整项迹的外侧，才能恰好与 $\operatorname{Tr}(\mathbb{1})=2$ 抵消得出 $\vec{\boldsymbol{n}}$。

纯度 $\operatorname{Tr}(\rho^2)$ 与本征值判定

平方 $\rho^2 = \frac{1}{4}\left[(1+|\vec{\boldsymbol{n}}|^2)\mathbb{1} + 2\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{\sigma}}\right]$ 并取迹，立刻得到纯度判据（Gerry–Knight 附录 A §A.1 式 A15）：

$$\operatorname{Tr}(\rho^2) = \frac{1 + |\vec{\boldsymbol{n}}|^2}{2} \quad \begin{cases} = 1, & |\vec{\boldsymbol{n}}|=1\text{（纯态）} \\ \in [1/2, 1), & |\vec{\boldsymbol{n}}|<1\text{（混态）} \end{cases}$$

记单位方向矢量 $\hat{\boldsymbol{u}} = \vec{\boldsymbol{n}}/|\vec{\boldsymbol{n}}|$，因 $\hat{\boldsymbol{u}}\cdot\vec{\boldsymbol{\sigma}}$ 本征值为 $\pm 1$（对应单位球面上沿 $\pm\hat{\boldsymbol{u}}$ 方向的一对对跖本征态），$\rho$ 的两个本征值分别为（式 A27）：$\lambda_\pm = \frac{1 \pm |\vec{\boldsymbol{n}}|}{2}$。

Worked Example

考虑一个统计系综：自旋以概率 $p_1 = \frac{3}{4}$ 处于 $|0\rangle$，以概率 $p_2 = \frac{1}{4}$ 处于 $|+\rangle = \frac{1}{\sqrt{2}}(|0\rangle + |1\rangle)$。

  1. 构造混态密度矩阵并用迹公式求 Bloch 矢量。 由正确投影叠加 $\rho = p_1|0\rangle\langle 0| + p_2|+\rangle\langle +|$：
    2. $$\rho = \frac{3}{4}\begin{pmatrix}1 & 0 \\ 0 & 0\end{pmatrix} + \frac{1}{4}\begin{pmatrix}1/2 & 1/2 \\ 1/2 & 1/2\end{pmatrix} = \begin{pmatrix} 7/8 & 1/8 \\ 1/8 & 1/8 \end{pmatrix}.$$

用 $\vec{\boldsymbol{n}} = \operatorname{Tr}(\rho\vec{\boldsymbol{\sigma}})$（等价于 $\frac{3}{4}(0,0,1) + \frac{1}{4}(1,0,0)$）算得：

$$n_x = \frac{1}{8} + \frac{1}{8} = \frac{1}{4},\qquad n_y = 0,\qquad n_z = \frac{7}{8} - \frac{1}{8} = \frac{3}{4} \implies \vec{\boldsymbol{n}} = \left(\frac{1}{4},\; 0,\; \frac{3}{4}\right).$$

  1. 求模长 $|\vec{\boldsymbol{n}}|$、纯度 $\operatorname{Tr}(\rho^2)$ 与本征值 $\lambda_\pm$。
    2. $$|\vec{\boldsymbol{n}}| = \sqrt{\left(\frac{1}{4}\right)^2 + \left(\frac{3}{4}\right)^2} = \frac{\sqrt{10}}{4} \approx 0.7906 < 1,$$
    $$\operatorname{Tr}(\rho^2) = \frac{1 + |\vec{\boldsymbol{n}}|^2}{2} = \frac{1 + 10/16}{2} = \frac{13}{16} = 0.8125 < 1,\qquad \lambda_\pm = \frac{1 \pm \sqrt{10}/4}{2} = \frac{4 \pm \sqrt{10}}{8}.$$

可见 $\vec{\boldsymbol{n}}$ 落在球内，纯度严格小于 $1$，确认为混态。

将单比特幺正门映射为 Bloch 矢量的三维旋转

本步要点 (TL;DR)
  • 幺正门 $U = e^{-i\theta\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}}$ 使密度矩阵演化为 $\rho_f = U\rho_0 U^\dagger$。
  • 由三维旋转公式 $U(\vec{\boldsymbol{n}}_0\cdot\vec{\boldsymbol{\sigma}})U^\dagger = R_{\vec{\boldsymbol{n}}\cdot\theta}(\vec{\boldsymbol{n}}_0)\cdot\vec{\boldsymbol{\sigma}}$，推得 $\vec{\boldsymbol{n}}_f = R_{\vec{\boldsymbol{n}}\cdot\theta}(\vec{\boldsymbol{n}}_0)$。
  • 这建立起算符空间幺正门与 Bloch 球右手定则三维绕轴旋转之间的严格同构，并完全消除整体相位干扰。

证明 $U\rho_0 U^\dagger$ 严格等价于绕轴三维旋转

设初态（纯态或混态均可）的密度矩阵为 $\rho_0 = \frac{\mathbb{1} + \vec{\boldsymbol{n}}_0\cdot\vec{\boldsymbol{\sigma}}}{2}$。对其施加由磁共振脉冲实现的单比特幺正门 $U = e^{-i\theta\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}}$（其中 $\vec{\boldsymbol{n}}$ 为单位转轴，$\theta = \Omega_{\text{eff}}t$ 为旋转角度），末态密度矩阵变为 $\rho_f = U\rho_0 U^\dagger$。由于 $U\mathbb{1}U^\dagger = \mathbb{1}$，只需变换 $\vec{\boldsymbol{n}}_0\cdot\vec{\boldsymbol{\sigma}}$ 一项。

回顾在「旋波近似与相互作用图像」中建立的三维旋转（Rodrigues）恒等式 $e^{-i\theta\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}}(\vec{\boldsymbol{r}}\cdot\vec{\boldsymbol{S}})e^{i\theta\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}} = R_{\vec{\boldsymbol{n}}\cdot\theta}(\vec{\boldsymbol{r}})\cdot\vec{\boldsymbol{S}}$，两边同乘以 $2$（利用 $\vec{\boldsymbol{\sigma}}=2\vec{\boldsymbol{S}}$）并代换 $\vec{\boldsymbol{r}}\to\vec{\boldsymbol{n}}_0$，立即得到：

$$U(\vec{\boldsymbol{n}}_0\cdot\vec{\boldsymbol{\sigma}})U^\dagger = R_{\vec{\boldsymbol{n}}\cdot\theta}(\vec{\boldsymbol{n}}_0)\cdot\vec{\boldsymbol{\sigma}}$$

再套用迹反演公式（式 1.39–1.40），末态的 Bloch 矢量为：

$$\vec{\boldsymbol{n}}_f = \operatorname{Tr}(\rho_f\vec{\boldsymbol{\sigma}}) = \operatorname{Tr}\!\left(\frac{\mathbb{1} + R_{\vec{\boldsymbol{n}}\cdot\theta}(\vec{\boldsymbol{n}}_0)\cdot\vec{\boldsymbol{\sigma}}}{2}\vec{\boldsymbol{\sigma}}\right) = R_{\vec{\boldsymbol{n}}\cdot\theta}(\vec{\boldsymbol{n}}_0)$$

其中右手定则表示：右手大拇指指向 $\vec{\boldsymbol{n}}$，四指弯曲方向即正角度 $\theta$ 的旋转方向；因为正交旋转保持长度不变（$|\vec{\boldsymbol{n}}_f|=|\vec{\boldsymbol{n}}_0|$），幺正门既能转动球面纯态，也能等距旋转球内混态而不改变纯度。特别地，当转角取 $\theta = \pi$ 时，三维绕轴旋转化为关于转轴 $\vec{\boldsymbol{n}}$ 的轴对称反射：$R_{\vec{\boldsymbol{n}}\cdot\pi}(\vec{\boldsymbol{n}}_0) = 2(\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{n}}_0)\vec{\boldsymbol{n}} - \vec{\boldsymbol{n}}_0$（沿 $\vec{\boldsymbol{n}}$ 的分量不变，垂直分量反向）。

几何与代数的统一：核对共振 $\pi/2$ 脉冲

在「有效场演化与拉比跃迁概率」中，我们曾直接由 $U_x(\pi/2) = e^{-i(\pi/2)S_x}$ 算出对基态 $|1\rangle$ 的末态为 $|\psi_f\rangle = \frac{1}{\sqrt{2}}(|1\rangle - i|0\rangle)$。很多人容易困惑为何 $-i$ 乘在 $|0\rangle$ 上却对应 $+y$ 轴？将它提出整体相位 $-i$ 改写为 $-i\frac{1}{\sqrt{2}}(|0\rangle + i|1\rangle) = -i|+y\rangle$ 便豁然开朗！在 Bloch 球上，南极 $\vec{\boldsymbol{n}}_0=(0,0,-1)$ 依右手定则绕 $+x$ 轴转过 $+90^\circ$，轨迹正好沿着大圆扫到赤道 $+y$ 轴上的 $\vec{\boldsymbol{n}}_f = (0,+1,0)$。

Worked Example

以初态 $|1\rangle$（即南极 $\vec{\boldsymbol{n}}_0 = (0, 0, -1)$）为例，分别用几何旋转与代数态矢追踪两种幺正门的作用。

  1. 追踪共振 $x$ 轴 $\pi/2$ 脉冲 $U_x(\pi/2) = e^{-i(\pi/2)S_x}$。
  • *几何路线：* 右手拇指沿 $+x=(1,0,0)$ 轴，四指从 $+y$ 弯向 $+z$ 再到 $-y$、$-z$；故把 $-z=(0,0,-1)$ 顺四指转 $+90^\circ$ 恰好落在 $+y$ 轴，得 $\vec{\boldsymbol{n}}_f = (0, 1, 0)$。
  • *代数验证：* $U_x(\pi/2)|1\rangle = \frac{1}{\sqrt{2}}(\mathbb{1} - i\sigma_x)|1\rangle = \frac{1}{\sqrt{2}}(|1\rangle - i|0\rangle)$，密度矩阵为 $\frac{1}{2}\begin{pmatrix}1 & -i \\ i & 1\end{pmatrix} = \frac{\mathbb{1}+\sigma_y}{2}$，给出 $\vec{\boldsymbol{n}}_f = (0, 1, 0)$。
  1. 追踪绕斜轴 $\vec{\boldsymbol{n}} = \frac{1}{\sqrt{2}}(1, 0, 1)$ 转动 $\theta = \pi$ 的门 $U = e^{-i\pi\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{S}}}$。
  • *几何路线：* $\vec{\boldsymbol{n}}$ 平分 $+x$ 与 $+z$ 轴，绕它旋转 $\pi$ 的公式为 $R_{\vec{\boldsymbol{n}}\cdot\pi}(\vec{\boldsymbol{n}}_0) = 2(\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{n}}_0)\vec{\boldsymbol{n}} - \vec{\boldsymbol{n}}_0$。代入 $\vec{\boldsymbol{n}}\cdot\vec{\boldsymbol{n}}_0 = -\frac{1}{\sqrt{2}}$ 得：

$$\vec{\boldsymbol{n}}_f = 2\left(-\frac{1}{\sqrt{2}}\right)\frac{1}{\sqrt{2}}(1,0,1) - (0,0,-1) = (-1, 0, 0),$$

对应赤道 $-x$ 态 $\frac{1}{\sqrt{2}}(|0\rangle - |1\rangle)$。

  • *代数验证：* $U = \cos\frac{\pi}{2}\mathbb{1} - i\sin\frac{\pi}{2}\frac{\sigma_x + \sigma_z}{\sqrt{2}} = -\frac{i}{\sqrt{2}}\begin{pmatrix}1 & 1 \\ 1 & -1\end{pmatrix}$，作用在 $|1\rangle$ 上给出 $-i\frac{|0\rangle - |1\rangle}{\sqrt{2}}$，整体相位 $-i$ 在 $\rho_f$ 中消去，同样得到 $\vec{\boldsymbol{n}}_f = (-1, 0, 0)$。

第 6 课 Step 1 · bs-first-frame-and-axis-tilt

一重旋转系变换与自旋轴倾斜

本步要点 (TL;DR)
  • 把远失谐横向驱动 $\Omega'[\cos(\omega' t+\varphi')S_x+\sin(\omega' t+\varphi')S_y]$ 并入哈密顿量（反旋项 ① 对应 $\Omega'=\Omega,\omega'=-\omega,\varphi'=-\varphi$）。
  • 作第一重变换 $U_i' = e^{-i(\omega' t+\varphi')S_z}$ 定格非共振项，得静态块 ③ $= (\omega_0-\omega')S_z + \Omega' S_x$。
  • 绕 $y$ 轴微倾 $\theta$ 对角化 ③（含教材两处勘误），并利用快变平均与 $\cos^2(\theta/2)\approx 1$ 化简主驱动。

纳入一般非共振横向驱动

保留主驱动（幅值 $\Omega$、频率 $\omega$、初相位 $\varphi$）的同时，再加入一路任意远失谐横向驱动（参数 $\Omega'$、$\omega'$、$\varphi'$）：

$$H = \omega_0 S_z + \Omega\left[\cos(\omega t + \varphi)S_x + \sin(\omega t + \varphi)S_y\right] + \Omega'\left[\cos(\omega' t + \varphi')S_x + \sin(\omega' t + \varphi')S_y\right]$$

若取 $\Omega' = \Omega$、$\omega' = -\omega$、$\varphi' = -\varphi$，第三项就正好还原上一课忽略的反向旋转项 ①（因为 $\cos(-\omega t-\varphi)=\cos(\omega t+\varphi)$ 而 $\sin(-\omega t-\varphi)=-\sin(\omega t+\varphi)$）。

第一重变换与量化轴倾斜

为先定格 $\Omega'$ 项，作第一重相互作用图像变换 $U_i' = e^{-i(\omega' t + \varphi')S_z}$。由于只消去了含 $\omega' t + \varphi'$ 的相角，求导修正给出 $-\omega' S_z$，主驱动相角变为 $\alpha(t) = (\omega-\omega')t + (\varphi-\varphi')$：

$$H_I' = \underbrace{(\omega_0 - \omega')S_z + \Omega' S_x}_{\text{③}} + \Omega\left[\cos\alpha(t)\,S_x + \sin\alpha(t)\,S_y\right]$$

不含时的静态块 ③ 在 $x\text{-}z$ 平面构成一个略微歪斜的有效矢量。假设处于远失谐弱微扰区 $|\Omega'| \ll |\omega_0 - \omega'|$，绕 $y$ 轴旋转小角度 $\theta$（$\tan\theta = \frac{\Omega'}{\omega_0-\omega'}$）定义新量化轴：

$$S_z' = \cos\theta\,S_z + \sin\theta\,S_x, \qquad S_x' = \cos\theta\,S_x - \sin\theta\,S_z, \qquad S_y' = S_y$$

令 $\cos\theta = \frac{|\omega_0 - \omega'|}{\sqrt{(\omega_0 - \omega')^2 + \Omega'^2}} > 0$、$\sin\theta = \operatorname{sgn}(\omega_0-\omega')\frac{\Omega'}{\sqrt{(\omega_0-\omega')^2+\Omega'^2}}$，代入立得 $(\omega_0-\omega')S_z + \Omega' S_x = \operatorname{sgn}(\omega_0-\omega')\sqrt{(\omega_0-\omega')^2 + \Omega'^2}(\cos\theta\,S_z + \sin\theta\,S_x)$，从而对 $\omega_0 > \omega'$ 与 $\omega_0 < \omega'$ 皆严格对角化块 ③ 为 $\operatorname{sgn}(\omega_0-\omega')\sqrt{(\omega_0-\omega')^2+\Omega'^2}\,S_z'$。注意教材勘误 1：原书式 (1.19) 下方漏印了平方，分母写作 $\sqrt{(\omega_0-\omega')+\Omega'^2}$，正确必须保留平方 $(\omega_0-\omega')^2$。

接着把 $S_x = \cos\theta\,S_x' + \sin\theta\,S_z'$、$S_y = S_y'$ 代入主驱动项。先舍去随 $|\omega-\omega'|$ 高频振荡的 $\Omega\sin\theta\cos\alpha(t)\,S_z'$ 项：它沿 $S_z'$ 平均为零，积分相角误差上限仅 $\frac{\Omega\sin\theta}{|\omega-\omega'|} \sim \frac{\Omega\Omega'}{(\omega_0-\omega')^2} \sim 4\times 10^{-6}\text{ rad}$，而块 ③ 中的静态能隙拉伸会在第二重旋转系下随时间线性积累，绝不能舍。再用 $\cos\theta = \cos^2(\theta/2) - \sin^2(\theta/2)$ 与 $1 = \cos^2(\theta/2) + \sin^2(\theta/2)$ 拆解：

$$\cos\alpha\,\cos\theta\,S_x' + \sin\alpha\,S_y' = \cos^2\frac{\theta}{2}(\cos\alpha\,S_x' + \sin\alpha\,S_y') - \sin^2\frac{\theta}{2}(\cos\alpha\,S_x' - \sin\alpha\,S_y')$$

舍去极小的 $\sin^2(\theta/2)$ 反向项后得：

$$H_I' \approx \operatorname{sgn}(\omega_0-\omega')\sqrt{(\omega_0-\omega')^2 + \Omega'^2}\,S_z' + \Omega\cos^2\frac{\theta}{2}\left[\cos\alpha(t)\,S_x' + \sin\alpha(t)\,S_y'\right]$$

这里注意教材勘误 2：原书式 (1.20) 下方误将 $\cos\theta \approx 1 - \frac{1}{2}\big(\frac{\Omega'}{\omega_0-\omega'}\big)^2$ 的分母印成 $\omega - \omega'$（漏掉下标 $0$）。在弱微扰下 $\cos^2(\theta/2) \approx 1 - \frac{1}{4}\big(\frac{\Omega'}{\omega_0-\omega'}\big)^2 \approx 1$；而且 $(S_x', S_y', S_z')$ 与 $(S_x, S_y, S_z)$ 构成严格幺正等价的自旋 $1/2$ 代数（$U_i''$ 围绕 $S_z'$ 转动），本征态投影偏差 $\sin^2(\theta/2) = \frac{1-\cos\theta}{2} \sim 10^{-6}\text{--}10^{-4}$ 极微，因此可直接沿用 $(S_x, S_y, S_z)$ 符号表象并取 $\cos^2(\theta/2)\approx 1$，只保留斜边能隙拉伸！

Worked Example

设某自旋在反向旋转项 ① 干扰下满足 $\omega_0/(2\pi) = 2.5\text{ GHz}$，反向项 $\omega'/(2\pi) = -2.5\text{ GHz}$、$\Omega'/(2\pi) = 10\text{ MHz}$，主驱动典型幅值与频率为 $\Omega/(2\pi) = 10\text{ MHz}$、$\omega \approx \omega_0$。我们来检验各近似量级为何能成立。

  1. 计算轴向系数差与轴倾角 $\theta$。
    2. $$(\omega_0 - \omega')/(2\pi) = 5000\text{ MHz}, \qquad \tan\theta = \frac{10}{5000} = 2 \times 10^{-3} \implies \sin\theta \approx 2\times 10^{-3}.$$
  1. 对比舍去的纵向快变项与保留的静态拉伸。 舍去项 $\Omega\sin\theta\cos\alpha(t)\,S_z'$ 幅值达 $10\text{ MHz}\times 2\times 10^{-3} = 20\text{ kHz}$，但它以 $|\omega-\omega'|/(2\pi) \approx 5\text{ GHz}$ 振荡平均为零，积分相角界限仅 $\frac{20\text{ kHz}}{5\text{ GHz}} = 4\times 10^{-6}\text{ rad}$；而块 ③ 斜边 $\sqrt{5000^2 + 10^2}\text{ MHz}$ 相对于 $5000\text{ MHz}$ 恒定拉长了 $10\text{ kHz}$，会随时间线性累加相移，故必须保留。
  1. 核对态重叠偏差与幺正等价表象。 用勘误修正后的展式算得 $1 - \cos\theta \approx \frac{1}{2}(2\times 10^{-3})^2 = 2\times 10^{-6}$，态基重叠偏离与 $\sin^2(\theta/2) = \frac{1-\cos\theta}{2} \approx 1\times 10^{-6}$（$\cos^2(\theta/2) \approx 1 - 1\times 10^{-6}$）。因 $(S_x', S_y', S_z')$ 与 $(S_x, S_y, S_z)$ 满足完全等价的自旋 $1/2$ 代数且态基几乎重合，继续在 $S_{x,y,z}$ 表象下写有效哈密顿量即可兼顾简洁与高精度。

第 6 课 Step 2 · bs-second-frame-and-shift-formula

二次变换导出 Bloch-Siegert 平移与旋波边界

本步要点 (TL;DR)
  • 作第二重变换 $U_i'' = e^{-i[(\omega-\omega')t - \varphi']S_z}$，其中的 $-\varphi'$ 恰好消去主驱动相角里的 $-\varphi'$ 偏置。
  • 二阶展开给出一般 Bloch-Siegert 平移 $\Delta_{\text{BS}} = \frac{\Omega'^2}{2(\omega_0 - \omega')}$（修正教材错印 Δ_SB）。
  • 反旋项极限为 $\Delta_{\text{BS}} = \frac{\Omega^2}{2(\omega_0+\omega)} \approx \frac{\Omega^2}{4\omega_0}$，从而把旋波近似成立条件定量化为 $\frac{\Omega}{4\omega_0} \ll 1$。

第二重相互作用变换与相位抵消

在等价自旋表象与 $\cos^2(\theta/2)\approx 1$ 下，第一重旋转系哈密顿量化简为以频率差 $(\omega-\omega')$ 旋转的准单色驱动形式：

$$H_I' \approx \operatorname{sgn}(\omega_0-\omega')\sqrt{(\omega_0-\omega')^2 + \Omega'^2}\,S_z + \Omega\left\{\cos\left[(\omega-\omega')t + (\varphi-\varphi')\right]S_x + \sin\left[(\omega-\omega')t + (\varphi-\varphi')\right]S_y\right\}$$

为消去余下的时间 $t$，坐进追踪主驱动拍频的第二重旋转系，作幺正变换

$$U_i'' = e^{-i\left[(\omega - \omega')t - \varphi'\right]S_z}.$$

请特别留意指数里附带的常数相角 $-\varphi'$：一方面，对时间求导只对 $(\omega-\omega')t$ 起作用，于是 $-U_i''^\dagger i\frac{\partial}{\partial t}U_i'' = -(\omega-\omega')S_z$；另一方面，由三维旋转公式，整个横向矢量绕 $z$ 轴顺时针转回角度 $(\omega-\omega')t - \varphi'$，令相角变为

$$[(\omega-\omega')t + \varphi - \varphi'] - [(\omega-\omega')t - \varphi'] = \varphi,$$

正好把第一重变换遗留的 $-\varphi'$ 偏置精确抵消，彻底复原出纯粹只含主驱动初相位 $\varphi$ 的不含时哈密顿量：

$$H_I = \left[\operatorname{sgn}(\omega_0-\omega')\sqrt{(\omega_0-\omega')^2 + \Omega'^2} - (\omega - \omega')\right]S_z + \Omega\left(\cos\varphi\,S_x + \sin\varphi\,S_y\right)$$

导出 Bloch-Siegert 平移与旋波近似定量判据

当 $|\Omega'| \ll |\omega_0 - \omega'|$ 时，利用 $\sqrt{a^2 + b^2} \approx |a| + \frac{b^2}{2|a|}$ 并注意 $\operatorname{sgn}(\omega_0-\omega')|a| = \omega_0-\omega'$ 与 $\operatorname{sgn}(\omega_0-\omega')/|a| = 1/(\omega_0-\omega')$，方括号内的纵向系数展开为：

$$\left[(\omega_0 - \omega') + \frac{\Omega'^2}{2(\omega_0 - \omega')}\right] - (\omega - \omega') = \omega_0 + \Delta_{\text{BS}} - \omega$$

于是得到非共振横向项引起的二阶共振频移——Bloch-Siegert 平移（注意教材勘误 3：原书式 (1.23) 下方错印为 $\Delta_{\text{SB}}$，规范写法为 $\Delta_{\text{BS}}$）：

$$\Delta_{\text{BS}} = \frac{\Omega'^2}{2(\omega_0 - \omega')}$$

对比上一课的 $H_I = (\omega_0 - \omega)S_z + \Omega(\cos\varphi\,S_x + \sin\varphi\,S_y)$，令此处 $S_z$ 系数 $\omega_0 + \Delta_{\text{BS}} - \omega = 0$，即得真实共振频率上移至 $\omega_{\text{res}} = \omega_0 + \Delta_{\text{BS}}$。

将该通式代回旋波近似忽略的反向旋转项 ①（$\Omega'=\Omega$，$\omega'=-\omega \approx -\omega_0$），立即得出反向项引起的频移：

$$\Delta_{\text{BS}} = \frac{\Omega^2}{2(\omega_0 + \omega)} \approx \frac{\Omega^2}{4\omega_0}$$

若 $\omega_0/(2\pi) \sim 2.5\text{ GHz}$，则 $2(\omega_0+\omega)/(2\pi) \sim 10\text{ GHz}$。将此平移量与横向驱动耦合强度 $\Omega$ 对比，得到旋波近似成立的定量边界：

$$\frac{\Delta_{\text{BS}}}{\Omega} \approx \frac{\Omega}{4\omega_0} \ll 1$$

通常要求 $\Omega / \omega_0 \lesssim 0.05$（此时频移不及耦合强度 $\Omega$ 的 $1.25\%$）；而在精密光谱或长脉冲演化中，还需额外满足累积相位误差 $|\Delta_{\text{BS}}| t_{\text{p}} \ll 1$，否则必须将共振点校准到 $\omega_0 + \Delta_{\text{BS}}$。

Worked Example

取电子自旋能隙 $\omega_0/(2\pi) = 5.0\text{ GHz} = 5000\text{ MHz}$，主驱动近共振（$\omega \approx \omega_0$），分别在弱驱动与超强驱动下计算反向旋转项导致的 Bloch-Siegert 平移 $\Delta_{\text{BS}}$，以检验旋波近似何时可靠、何时会显著失效。

  1. 常规弱驱动情形：$\Omega/(2\pi) = 10\text{ MHz}$。 此时 $\Omega/\omega_0 = 2\times 10^{-3} \ll 1$，代入近共振公式 $\Delta_{\text{BS}} \approx \Omega^2/(4\omega_0)$：
    2. $$\frac{\Delta_{\text{BS}}}{2\pi} \approx \frac{(10\text{ MHz})^2}{4 \times 5000\text{ MHz}} = \frac{100}{20000}\text{ MHz} = 5 \times 10^{-3}\text{ MHz} = 5\text{ kHz}.$$

频移与横向驱动耦合强度之比 $\Delta_{\text{BS}}/\Omega = 5\times 10^{-4}$，对于微秒量级以内的普通拉比脉冲完全可忽略，旋波近似极为精准。

  1. 超强驱动情形：$\Omega/(2\pi) = 1.0\text{ GHz} = 1000\text{ MHz}$。 此时 $\Omega/\omega_0 = 0.2$，不再远小于 $1$：
    2. $$\frac{\Delta_{\text{BS}}}{2\pi} \approx \frac{(1000\text{ MHz})^2}{4 \times 5000\text{ MHz}} = \frac{10^6}{20000}\text{ MHz} = 50\text{ MHz}.$$

此时 $\Delta_{\text{BS}}/\Omega = 0.05$，真实共振峰值从 $5.00\text{ GHz}$ 向上蓝移整整 $50\text{ MHz}$ 至 $5.05\text{ GHz}$。若仍天真地按旋波近似把频率设为 $\omega = 5.00\text{ GHz}$，将偏离共振高达 $50\text{ MHz}$，旋波近似明显失效。

第 6 课 Step 3 · bs-sign-level-repulsion-and-optical-stark

能级排斥符号律与光学色散 AC Stark 频移

本步要点 (TL;DR)
  • 由 $\Delta_{\text{BS}} = \frac{\Omega'^2}{2(\omega_0-\omega')}$：红失谐（$\omega'<\omega_0$）蓝移，蓝失谐（$\omega'>\omega_0$）红移，源于能级排斥。
  • 在量子光学色散区，虚光子交换给出 $\hat{H}_{\text{eff}} = \Delta_{\text{disp}}(|e\rangle\langle e| + 2\hat{a}^\dagger\hat{a}\,S_z)$（$\Delta_{\text{disp}}=\frac{\lambda^2}{\omega_0-\omega_c}$），受激项即 $\Delta_{\text{BS}}$。
  • 多音或旁支微波同样按 $\Delta_{\text{BS}}$ 移峰，可在固态多能级控制中作为寄生串扰误差预先校准。

符号反转与普遍的能级排斥规律

观察 $\Delta_{\text{BS}} = \frac{\Omega'^2}{2(\omega_0 - \omega')}$：分子 $\Omega'^2 \ge 0$ 恒非负，频移方向完全由失谐 $\omega_0 - \omega'$ 的符号决定：

  • 红失谐微扰（$\omega' < \omega_0$，含反旋项 $\omega'=-\omega$）：$\omega_0 - \omega' > 0 \implies \Delta_{\text{BS}} > 0$，共振频率上移（蓝移）。
  • 蓝失谐微扰（$\omega' > \omega_0$）：$\omega_0 - \omega' < 0 \implies \Delta_{\text{BS}} < 0$，共振频率下移（红移）。

在第一重旋转系中，两态顺序由 $(\omega_0-\omega')S_z$ 决定。当 $\omega' > \omega_0$ 时两态上下颠倒，斜边“拉大旋转系能隙 $|\omega_0-\omega'|$”反过来压缩实验室能隙 $\omega_0$。这种把邻近能级彼此推开的二阶耦合效应称作能级排斥（level repulsion）。

桥接量子光学：色散 AC Stark 频移与同构识别

对照 Gerry & Knight 第 4.8 节与附录 C，二能级原子耦合频率为 $\omega_c$ 的单模腔（耦合常数 $\lambda$），在无量纲自旋基下写作 $H_{\text{JC}} = \omega_0 S_z + \omega_c \hat{a}^\dagger \hat{a} + \lambda(S^+ \hat{a} + S^- \hat{a}^\dagger)$（$S^+ = |e\rangle\langle g|$、$S^- = |g\rangle\langle e|$）。当处于大失谐色散区（$|\omega_0 - \omega_c| \gg \lambda\sqrt{n+1}$）时，虚光子交换给出二阶对角哈密顿量：

$$\hat{H}_{\text{eff}} = \Delta_{\text{disp}}\left(|e\rangle\langle e| + 2\,\hat{a}^\dagger\hat{a}\,S_z\right), \qquad \Delta_{\text{disp}} = \frac{\lambda^2}{\omega_0 - \omega_c}$$

在 $n$ 光子态 $|n\rangle$ 上，$|e,n\rangle$ 移动 $(n+1)\Delta_{\text{disp}}$、$|g,n\rangle$ 移动 $-n\Delta_{\text{disp}}$，跃迁总频移为 $(2n+1)\frac{\lambda^2}{\omega_0-\omega_c}$（真空频移加受激 AC Stark 频移 $2n\frac{\lambda^2}{\omega_0-\omega_c}$）。将经典旋转驱动写为升降算符 $\Omega'(\cos\alpha\,S_x + \sin\alpha\,S_y) = \frac{\Omega'}{2}(e^{-i\alpha}S^+ + e^{i\alpha}S^-)$，对照 Jaynes–Cummings 耦合 $\lambda(S^+\hat{a} + S^-\hat{a}^\dagger)$ 及矩阵元 $\langle n-1|\hat{a}|n\rangle = \sqrt{n}$，立得半经典幅值对应 $\frac{1}{2}\Omega' \leftrightarrow \lambda\sqrt{n}$（即 $\Omega' = 2\lambda\sqrt{n}$）：

$$2n\,\frac{\lambda^2}{\omega_0 - \omega_c} = \frac{(2\lambda\sqrt{n})^2}{2(\omega_0 - \omega_c)} = \frac{\Omega'^2}{2(\omega_0 - \omega_c)} = \Delta_{\text{BS}}$$

因此磁共振 Bloch-Siegert 平移与光学色散 AC Stark 频移本质完全相同。

多音寄生误差与横向轴倾斜特征

在多量子比特或三能级固态自旋（如金刚石 NV 色心强驱动 $-1 \leftrightarrow 0$ 时寄生耦合旁支 $0 \leftrightarrow +1$）中，远失谐横向微波会在目标跃迁上叠加 $\Delta_{\text{BS}}$ 移峰误差，须提前按 $\Delta_{\text{BS}}$ 作失谐补偿。不同于仅沿 $S_z$ 轴的纵向调制（不倾斜量化轴），所有非共振横向项都通过微倾 $S_z$ 量化轴引发二阶能级排斥来移动中心共振频率。

Worked Example

某电子自旋跃迁频率为 $\omega_0/(2\pi) = 3.0\text{ GHz} = 3000\text{ MHz}$。实验上除了弱探测微波外，附近还存在一路连续工作的寄生横向微波（驱动幅值 $\Omega'/(2\pi) = 20\text{ MHz}$）。我们计算该寄生驱动在不同频段下造成的共振偏移，并与严格平方根斜边公式核对精度。

  1. 寄生音在主跃迁下方（红失谐）：$\omega'/(2\pi) = 2.8\text{ GHz}$。 此时 $(\omega_0 - \omega')/(2\pi) = +200\text{ MHz} > 0$，代入公式：
    2. $$\frac{\Delta_{\text{BS}}}{2\pi} = \frac{(20\text{ MHz})^2}{2 \times (+200\text{ MHz})} = +1.00\text{ MHz}.$$

能级排斥把目标跃迁频率向上推至 $3.001\text{ GHz}$（蓝移）。

  1. 寄生音在主跃迁上方（蓝失谐）：$\omega'/(2\pi) = 3.2\text{ GHz}$。 此时 $(\omega_0 - \omega')/(2\pi) = -200\text{ MHz} < 0$，符号反转：
    2. $$\frac{\Delta_{\text{BS}}}{2\pi} = \frac{(20\text{ MHz})^2}{2 \times (-200\text{ MHz})} = -1.00\text{ MHz}.$$

高于共振的寄生驱动把跃迁频率向下压至 $2.999\text{ GHz}$（红移）。

  1. 核对二阶展开相对于精确斜边公式的误差。 严格一重旋转系本征频率偏移量为
    2. $$\frac{|\Delta_{\text{exact}}|}{2\pi} = \sqrt{200^2 + 20^2} - 200 \approx 0.997512\text{ MHz}.$$

可见二阶公式给出的 $1.00\text{ MHz}$ 与严格斜边解之间的相对误差仅为 $\frac{1.00 - 0.997512}{0.997512} \approx 0.249\% < 0.25\%$，在此参数区兼具高精度与符号直观性。

直接前置依赖：旋波近似与相互作用图像（rotating-wave-and-frame） 、 横向非共振项与 Bloch-Siegert 平移（bloch-siegert-shift）

当交变磁场不再垂直于静磁场，或者再叠加纵向调制时

前面处理横向旋转驱动时，我们默认线圈严格垂直于静磁场（即纵向分量 $B_z = 0$）。但真实实验中线圈往往存在倾角，或者实验者会主动沿 $z$ 轴再施加射频调制。此时纵轴 $S_z$ 系数随时间振荡，能隙本身在不停呼吸。

本课不再局限于常速率旋转参考系，而是构造含时相互作用图像把纵轴调制整体吸收进幺正变换相位中，借助贝塞尔函数展开揭示边带共振梳、载波抑制与突破功放带宽的倍频激发原理。

前置衔接（Recap）

前置回顾 · 旋波近似与相互作用图像（rotating-wave-and-frame）

旋波近似保留角动量匹配的逆时针横向分量，利用 $U_i = e^{-i\omega t S_z}$ 与升降算符恒等式 $U_i^\dagger S^+ U_i = e^{i\omega t}S^+$ 可消去横向驱动的时间依赖。

前置回顾 · 横向非共振项与 Bloch-Siegert 平移（bloch-siegert-shift）

强或远失谐横向驱动分量会带来微小频率偏移而超出主共振简化范畴，本课只要求主共振条件成立；该项可作选学背景。

第 7 课 Step 1 · sideband-time-dependent-frame-and-jacobi-anger

含时参考系与 Jacobi–Anger 边带展开

本步要点 (TL;DR)
  • 含时纵向调制 $H_z = \Omega_z\cos(\omega_z t + \varphi_z)S_z$ 与横向驱动共同进入总哈密顿量。
  • 引入无量纲调制指数 $\chi = \Omega_z / \omega_z$ 与含时变换 $U_i(t) = e^{-i[\omega_0 t + \chi\sin(\omega_z t + \varphi_z)]S_z}$，同时消去静态项与纵向调制项。
  • 经 Jacobi–Anger 展开后，单频驱动裂分为位于 $\omega_0 + n\omega_z$ 的无限边带梳，第 $n$ 阶耦合幅度为 $|J_n(\chi)|\Omega$。

含时纵向驱动模型与 $\frac{1}{2}$ 因子勘误

实际线圈不垂直于 $z$ 轴或外加独立纵向交变场时，产生纵向扰动 $H_z = -\gamma_e B_z\cos(\omega t+\varphi)S_z$，一般写作 $H_z = \Omega_z\cos(\omega_z t + \varphi_z)S_z$（对比横向线偏振拆为圆偏振时定义 $2\Omega = -\gamma_e B_x$，纵向项无须拆分，直接对应 $\Omega_z = -\gamma_e B_z$）。结合静态项与旋波近似横向分量，总哈密顿量为：

$$H = \big[\omega_0 + \Omega_z\cos(\omega_z t + \varphi_z)\big]S_z + \Omega\big[\cos(\omega t + \varphi)S_x + \sin(\omega t + \varphi)S_y\big]$$

教材勘误提示： 用 $S_x = \frac{1}{2}(S^+ + S^-)$ 与 $S_y = \frac{1}{2}(-iS^+ + iS^-)$ 改写横向项时，必须保留 $\frac{1}{2}$ 因子，即 $\cos(\omega t+\varphi)S_x + \sin(\omega t+\varphi)S_y = \frac{1}{2}(e^{-i(\omega t+\varphi)}S^+ + \text{h.c.})$；原讲义式 (1.26)、(1.28)、(1.30)、(1.31) 漏写了 $S^+$ 前的 $\frac{1}{2}$。

含时相互作用图像与 Jacobi–Anger 展开

设无量纲纵向调制指数 $\chi = \Omega_z/\omega_z$，取含时相位 $\Theta(t) = \omega_0 t + \chi\sin(\omega_z t + \varphi_z)$ 构造含时相互作用图像变换 $U_i(t) = e^{-i\Theta(t)S_z}$（略去 $t=0$ 积分常数 $-\chi\sin\varphi_z$ 仅固定零时刻参考系偏置，不改变 $H_I$）。代入通式 $H_I = U_i^\dagger H U_i - U_i^\dagger i\partial_t U_i$：因算符方向 $S_z$ 固定，$[\Theta(t)S_z, \dot{\Theta}(t)S_z] = 0$ 使指数可按标量链式法则直接求导（无须时间排序）得 $\partial_t U_i = -i\dot{\Theta}(t)S_z U_i$；又因 $[U_i(t), S_z] = 0$（即与 $\omega_0 S_z + H_z$ 对易），静态与纵向 $S_z$ 项穿过 $U_i^\dagger(\cdots)U_i$ 后原样保留，恰与导数项 $-[\omega_0 + \Omega_z\cos(\omega_z t+\varphi_z)]S_z$ 精确抵消！同时 $U_i^\dagger S^+ U_i = e^{i\Theta(t)}S^+$ 把纵向振荡转为周期相位调制：

$$H_I = \frac{\Omega}{2}\Big(e^{i[(\omega_0-\omega)t-\varphi]}e^{i\chi\sin(\omega_z t+\varphi_z)}S^+ + \text{h.c.}\Big)$$

因 $e^{i\chi\sin(\omega_z t+\varphi_z)} = \sum_{n=-\infty}^\infty A_n e^{i n\omega_z t}$，令 $\alpha' = \omega_z t$、$\alpha = \alpha' + \varphi_z$，利用奇函数 $\sin(n\alpha - \chi\sin\alpha)$ 在 $[-\pi,\pi]$ 积分为零，得 $A_n = e^{i n\varphi_z}\frac{1}{\pi}\int_0^\pi \cos(n\alpha - \chi\sin\alpha)\,d\alpha = e^{i n\varphi_z}J_n(\chi)$，其中 $J_n(\chi)$ 为第 $n$ 阶第一类贝塞尔函数（一并修正式 (1.29)–(1.32) 将 $\chi$ 误印为 $x$ 的笔误）。代回即得无限边带之和：

$$H_I = \frac{1}{2}\sum_{n=-\infty}^{\infty} J_n(\chi)\Omega\, e^{i(n\varphi_z - \varphi)} e^{i(\omega_0 - \omega + n\omega_z)t} S^+ + \text{h.c.}$$

可见，单频驱动被调制成以 $\omega_0$ 为中心、间距为 $\omega_z$ 的共振梳 $\omega_0 + n\omega_z$，各阶强度由第一类贝塞尔函数 $|J_n(\chi)|$ 调控；当 $\chi \approx 2.4048$ 到达 $J_0(\chi)$ 首个零点时，$n=0$ 载波被完全抑制，能量转入 $n=\pm 1, \pm 2$ 等边带。

Worked Example

设自旋静态跃迁频率 $\omega_0/(2\pi) = 2000\text{ MHz}$，沿 $z$ 轴施加幅值 $\Omega_z/(2\pi) = 10\text{ MHz}$、调制频率 $\omega_z/(2\pi) = 50\text{ MHz}$（初相位 $\varphi_z = 0$）的纵向交流场，并配合横向驱动幅值 $\Omega/(2\pi) = 10\text{ MHz}$（$\varphi = 0$）。

  1. 计算纵向调制指数 $\chi$ 并写出含时变换 $U_i(t)$。 由定义直接相除：
    2. $$\chi = \frac{\Omega_z}{\omega_z} = \frac{10\text{ MHz}}{50\text{ MHz}} = 0.2, \qquad U_i(t) = \exp\!\Big(-i\big[\omega_0 t + 0.2\sin(\omega_z t)\big]S_z\Big).$$
  1. 写出修正后的边带展开式并读出共振位置。 保留 $S^+$ 前的 $\frac{1}{2}$ 因子并代入 $\varphi = \varphi_z = 0$ 与 $\chi = 0.2$：
    2. $$H_I = \frac{1}{2}\sum_{n=-\infty}^{\infty} J_n(0.2)\Omega\, e^{i(\omega_0 - \omega + n\omega_z)t} S^+ + \text{h.c.}$$

由共振条件 $\omega_0 - \omega + n\omega_z = 0$ 得等间距边带频率 $\omega/(2\pi) = 2000 + 50n\text{ MHz}$：

$$n=0: 2000\text{ MHz},\qquad n=\pm 1: 2050\text{ / }1950\text{ MHz},\qquad n=\pm 2: 2100\text{ / }1900\text{ MHz}.$$

  1. 计算前几阶边带的有效横向耦合幅度 $|J_n(0.2)|\Omega/(2\pi)$。 利用 $J_0(0.2) \approx 0.9900$、$|J_{\pm 1}(0.2)| \approx 0.09950$、$|J_{\pm 2}(0.2)| \approx 0.004983$：
    2. $$|J_0(0.2)|\frac{\Omega}{2\pi} \approx 9.900\text{ MHz},\qquad |J_{\pm 1}(0.2)|\frac{\Omega}{2\pi} \approx 0.995\text{ MHz},\qquad |J_{\pm 2}(0.2)|\frac{\Omega}{2\pi} \approx 0.0498\text{ MHz}.$$

各阶有效耦合均小于间距 $50\text{ MHz}$，各边带清晰分离。

第 7 课 Step 2 · sideband-single-resonance-and-effective-hi

可分辨边带条件与单边带有效哈密顿量

本步要点 (TL;DR)
  • 记边带失谐 $\Delta_n = \omega_0 - \omega + n\omega_z$；在可分辨条件 $|J_n(\chi)\Omega| \ll \omega_z$ 下至多一项共振。
  • 作二次变换 $U_2 = e^{+i\Delta_n t S_z}$ 得常系数 $H_{I,\text{eff}}^{(n)}$（并补齐教材式 (1.32) 漏掉的 $S_x$）。
  • 当 $\omega_z$ 过小使 $|J_n(\chi)\Omega| \ll \omega_z$ 失效时，多边带干涉须数值求解。

孤立单边带共振与二次旋转坐标系

记第 $n$ 阶边带的频率失谐为 $\Delta_n = \omega_0 - \omega + n\omega_z$。因为相邻边带间隔为 $\omega_z$，只要满足可分辨边带条件 $|J_m(\chi)\Omega| \ll \omega_z$（对所有主要阶次 $m$ 成立），且驱动频率 $\omega$ 接近某单一目标边带 $\omega_0 + n\omega_z$（即 $|\Delta_n| \lesssim |J_n(\chi)\Omega|$），则其余任何 $m \neq n$ 阶都满足 $|\Delta_m| = |\Delta_n + (m-n)\omega_z| \gtrsim \omega_z \gg |J_m(\chi)\Omega|$。这些非共振项高速振荡，在旋波近似下可平均忽略（高精度分析时仅贡献高阶小频移）。

仅保留第 $n$ 阶近共振项（保留 $\frac{1}{2}$ 因子）：

$$H_I^{(n)} \approx \frac{1}{2}J_n(\chi)\Omega\, e^{i(n\varphi_z - \varphi)} e^{i\Delta_n t} S^+ + \text{h.c.}$$

为消去残留的时间因子 $e^{i\Delta_n t}$，施加以正号为特征的二次相互作用图像变换 $U_2(t) = e^{+i\Delta_n t S_z}$。由于 $U_2$ 指数带正号，求导修正项 $-U_2^\dagger i\frac{\partial}{\partial t}U_2 = +\Delta_n S_z$ 为正，而 $U_2^\dagger S^+ U_2 = e^{-i\Delta_n t}S^+$ 恰好抵消 $e^{+i\Delta_n t}$。将 $\frac{1}{2}(e^{-i(\varphi-n\varphi_z)}S^+ + e^{i(\varphi-n\varphi_z)}S^-)$ 还原回 $S_x, S_y$，即得精确的常系数有效哈密顿量：

$$H_{I,\text{eff}}^{(n)} = \Delta_n S_z + J_n(\chi)\Omega\big[\cos(\varphi - n\varphi_z)S_x + \sin(\varphi - n\varphi_z)S_y\big]$$

教材勘误提示： 原讲义式 (1.32) 在 $\cos(\varphi - n\varphi_z)$ 后漏印了算符 $S_x$，必须补齐 $S_x$ 才是合法的横向自旋耦合项。

贝塞尔符号宇称与不可分辨边带区

注意负阶贝塞尔函数满足宇称恒等式 $J_{-n}(\chi) = (-1)^n J_n(\chi)$。当 $n$ 为负奇数（如 $n=-1$）且 $0 < \chi < 3.83$ 时，$J_{-1}(\chi) < 0$，等效于将横平面驱动轴额外翻转 $\pi$（而有效横向耦合强度大小仍为 $|J_n(\chi)|\Omega$）。此外，相位组合 $\varphi - n\varphi_z$ 说明纵向调制初相位 $\varphi_z$ 会按阶数 $n$ 线性传入有效旋转轴方位角，从而可通过调控 $\varphi_z$ 实现边带门控相移。

相反，若调制频率 $\omega_z$ 很低（例如同时叠加了低频射频场）导致 $|J_n(\chi)\Omega| \ll \omega_z$ 不再成立，相邻边带的失谐不再远大于耦合强度，多阶边带将同时发生激发并产生干涉拍频。此时单边带近似完全失效，不能再用上式解析求解，必须对完整的含时哈密顿量作数值演化计算。

Worked Example

承接上例（$\omega_0/(2\pi) = 2000\text{ MHz}$、$\omega_z/(2\pi) = 50\text{ MHz}$、$\Omega_z/(2\pi) = \Omega/(2\pi) = 10\text{ MHz}$，故 $\chi = 0.2$），将横向驱动频率调至 $\omega/(2\pi) = 2052\text{ MHz}$，取初相位 $\varphi = \pi/3$、$\varphi_z = \pi/6$。

  1. 筛选近共振边带并计算失谐 $\Delta_n/(2\pi)$。 代入 $\Delta_n = \omega_0 - \omega + n\omega_z$：
    2. $$\frac{\Delta_{+1}}{2\pi} = 2000 - 2052 + 50 = -2\text{ MHz}, \qquad \frac{\Delta_0}{2\pi} = -52\text{ MHz}, \qquad \frac{\Delta_{+2}}{2\pi} = +48\text{ MHz}.$$

因 $|J_1(0.2)\Omega|/(2\pi) \approx 0.995\text{ MHz} \ll 50\text{ MHz}$，可孤立保留 $n = +1$ 阶边带。

  1. 作二次变换 $U_2 = e^{+i\Delta_{+1} t S_z}$ 并计算有效相位角。 由 $\varphi - (+1)\varphi_z = \frac{\pi}{3} - \frac{\pi}{6} = \frac{\pi}{6}$，代入修正后的式 (1.32) 得：
    2. $$\frac{H_{I,\text{eff}}^{(+1)}}{2\pi} = (-2\text{ MHz})S_z + 0.995\text{ MHz}\left(\cos\frac{\pi}{6}\,S_x + \sin\frac{\pi}{6}\,S_y\right).$$
  1. 写出在 $\{|m_S=+1/2\rangle, |m_S=-1/2\rangle\}$ 基下的矩阵形式。 利用 $S_z = \frac{1}{2}\text{diag}(1,-1)$ 与 $\cos\frac{\pi}{6}S_x + \sin\frac{\pi}{6}S_y = \frac{1}{2}\begin{pmatrix} 0 & e^{-i\pi/6} \\ e^{i\pi/6} & 0 \end{pmatrix}$：
    2. $$\frac{H_{I,\text{eff}}^{(+1)}}{2\pi} \approx \begin{pmatrix} -1 & 0.4975\,e^{-i\pi/6} \\ 0.4975\,e^{+i\pi/6} & +1 \end{pmatrix}\text{ MHz} \approx \begin{pmatrix} -1 & 0.4309 - 0.2488i \\ 0.4309 + 0.2488i & +1 \end{pmatrix}\text{ MHz}.$$

可见整个含时边带问题被精确化为了一个失谐为 $-2\text{ MHz}$、有效耦合幅值为 $0.995\text{ MHz}$ 的静态二能级共振问题。

第 7 课 Step 3 · sideband-subharmonic-and-mas-transfer

倾斜线圈倍频激发与 MAS 边带迁移

本步要点 (TL;DR)
  • 倾斜单线圈同时产生 $\Omega$ 与同频 $\Omega_z$（$\omega_z = \omega$），得倍频共振 $\omega = \frac{1}{1-n}\omega_0$（$n \le 0$）。
  • 取 $n=-1$ 可用 $\omega_0/2$ 跨越功放带宽，小 $\chi$ 下有效耦合 $|J_{-1}(\chi)|\Omega \approx \frac{\Omega_z\Omega}{2\omega}$。
  • 魔角旋转（MAS）周期调制 $S_z$ 各向异性，产生 $\omega_0 + n\omega_r$ 旋转边带。

倾斜单线圈下的同源倍频激发条件

当实验中只有一根微波线圈且故意倾斜安装（$\theta_B \neq 90^\circ$）时，同一个交变源会同时产生横向耦合 $\Omega \propto B_x$ 与纵向调制 $\Omega_z \propto B_z$，因而纵向频率严格锁定为驱动频率 $\omega_z = \omega$（且 $\varphi_z = \varphi$）。将 $\omega_z = \omega$ 代入第 $n$ 阶边带失谐公式，令 $\Delta_n = 0$ 即得倍频（亚谐波）激发条件：

$$\Delta_n = \omega_0 - \omega + n\omega = \omega_0 + (n - 1)\omega = 0 \implies \omega = \frac{1}{1 - n}\omega_0 \quad (n = 0, -1, -2, \dots)$$

这里只有 $n \le 0$ 才对应正频率 $\omega > 0$：$n = 0$ 为基频共振 $\omega_0$；$n = -1$ 对应 $\omega = \omega_0/2$（吸取一个横向光子和一个同频纵向能量量子，共以二倍频跨越能隙）；$n = -2$ 对应 $\omega = \omega_0/3$。实际应用中，当自旋能隙（例如 $\omega_0/(2\pi) = 10\text{ GHz}$）超出实验室微波功放的带宽上限时，只需倾斜线圈并改用 $5\text{ GHz}$ 微波源驱动 $n = -1$ 阶边带即可实现共振翻转，必要时微调静磁场 $B_0$ 以对准目标能隙。

在小调制极限 $\chi = \Omega_z / \omega \ll 1$ 下，由贝塞尔积分定义展开 $\cos(\alpha - \chi\sin\alpha) = \cos\alpha\cos(\chi\sin\alpha) + \sin\alpha\sin(\chi\sin\alpha)$：前项关于 $\alpha = \pi/2$ 奇对称而在 $[0,\pi]$ 积分为零，小 $\chi$ 下 $\sin(\chi\sin\alpha) \approx \chi\sin\alpha$，故 $J_1(\chi) \approx \frac{1}{\pi}\int_0^\pi \chi\sin^2\alpha\,d\alpha = \frac{\chi}{2}$，再由宇称得 $J_{-1}(\chi) = -J_1(\chi) \approx -\frac{\chi}{2}$。因此二倍频有效耦合强度 $|J_{-1}(\chi)|\Omega \approx \frac{\chi}{2}\Omega = \frac{\Omega_z\Omega}{2\omega}$ 与单线圈驱动幅度成平方正比，适当提高驱动功率即可保持可用操控速率。

迁移至固体核磁魔角旋转（MAS）边带

同一套贝塞尔相位调制机制也支配着固体核磁共振的魔角旋转（MAS）。固体核自旋的化学位移各向异性与偶极耦合会在 $S_z$ 上引入依赖晶粒取向的频移；将样品绕与静磁场成魔角 $\arccos(1/\sqrt{3}) \approx 54.74^\circ$ 的转轴以机械角频率 $\omega_r$ 高速旋转后，静态平均偏移抵消，残留各向异性耦合随转角以 $\omega_r$ 谐波周期调制。进入含时相互作用图像积分并作 Jacobi–Anger 展开，谱线便在中心峰 $\omega_0$（$n=0$）两侧裂分为间隔 $\omega_r$ 的旋转边带（$\omega_0 + n\omega_r$）；提高转速 $\omega_r$ 会压低等效调制指数 $\chi$，将边带强度聚回中心峰。

Worked Example

某电子自旋处于静磁场中，静态跃迁频率为 $\omega_0/(2\pi) = 10\text{ GHz} = 10000\text{ MHz}$，而实验室功放仅能输出 $6\text{ GHz}$ 以下微波。现将单根线圈倾斜放置，在 $\omega/(2\pi) = 5\text{ GHz} = 5000\text{ MHz}$ 处同时产生 $\omega_z = \omega$ 的调制。

  1. 确定共振边带阶次 $n$。 代入同源共振公式 $\omega = \frac{1}{1-n}\omega_0$：
    2. $$5\text{ GHz} = \frac{10\text{ GHz}}{1 - n} \implies 1 - n = 2 \implies n = -1.$$
  1. 强驱动情形（$\Omega/(2\pi) = \Omega_z/(2\pi) = 50\text{ MHz}$）下的有效耦合。 计算调制指数 $\chi$ 与 $n=-1$ 阶贝塞尔幅值：
    2. $$\chi = \frac{\Omega_z}{\omega} = \frac{50\text{ MHz}}{5000\text{ MHz}} = 0.01, \qquad |J_{-1}(0.01)| = |-J_1(0.01)| \approx \frac{\chi}{2} = 0.005,$$
    $$|J_{-1}(\chi)|\frac{\Omega}{2\pi} \approx 0.005 \times 50\text{ MHz} = 0.25\text{ MHz} = 250\text{ kHz}.$$

注意由于 $\chi \ll 1$，此值几乎精确等于二次标度估算 $\frac{\Omega_z\Omega}{2\omega} / (2\pi) = \frac{50^2}{2\times 5000}\text{ MHz} = 250\text{ kHz}$。

  1. 对照弱驱动情形（$\Omega/(2\pi) = \Omega_z/(2\pi) = 10\text{ MHz}$）。 此时 $\chi = \frac{10}{5000} = 0.002$，$|J_{-1}(0.002)| \approx 0.001$，有效耦合降为：
    2. $$|J_{-1}(0.002)|\frac{\Omega}{2\pi} \approx 0.001 \times 10\text{ MHz} = 10\text{ kHz}.$$

将驱动幅度提高 $5$ 倍，二倍频有效耦合提升了 $5^2 = 25$ 倍（从 $10\text{ kHz}$ 跃升至 $250\text{ kHz}$），足以支撑实验中的弱激发调控。

本节总结

  • 含时参考系与 Jacobi–Anger 边带梳：构造含时变换 $U_i(t) = e^{-i[\omega_0 t + \chi\sin(\omega_z t+\varphi_z)]S_z}$（调制指数 $\chi = \Omega_z/\omega_z$）将纵向振荡化为 $S^+$ 的相位调制，展开后得到间距 $\omega_z$ 的共振梳 $\omega_0 + n\omega_z$，耦合强度由 $|J_n(\chi)|\Omega$ 给出（修正了讲义漏掉 $\frac{1}{2}$ 因子与 $J_n(x)\to J_n(\chi)$ 的笔误）。
  • 单边带常系数有效哈密顿量：在可分辨边带条件 $|J_n(\chi)\Omega| \ll \omega_z$ 下，定义失谐 $\Delta_n = \omega_0 - \omega + n\omega_z$ 并作二次变换 $U_2 = e^{+i\Delta_n t S_z}$，得到 $H_{I,\text{eff}}^{(n)} = \Delta_n S_z + J_n(\chi)\Omega[\cos(\varphi - n\varphi_z)S_x + \sin(\varphi - n\varphi_z)S_y]$（补齐了讲义漏印的 $S_x$）；若 $\omega_z$ 过小则多边带干涉须数值求解。
  • 同源倍频激发与 MAS 迁移：倾斜单个线圈使 $\omega_z = \omega$，由 $\omega = \frac{1}{1-n}\omega_0$（$n \le 0$）可用低频功放（如 $\omega_0/2$）实现二倍频跃迁；固体核磁魔角旋转（MAS）的旋转边带源于完全相同的 $S_z$ 周期相位调制机制。
