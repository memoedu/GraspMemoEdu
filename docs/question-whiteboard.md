# 题目白板

题目工具栏的「白板」打开分栏工作区。拖动中间分隔线调整宽度，也可以按方向键调整或使用「交换位置」。白板运行独立发布的 AnnotationCapture 编辑器。

进入 Topic 后，指导、记忆组块、只读来源和题目等正文页面的工具栏都提供白板。可手写、计算或用录音填入表达式。阅读和预览时，「提交」呈灰色且不可点击。进入可提交的作答阶段后才会启用「提交」。

- 画笔、形状、套索、橡皮、撤销和重做在白板内操作。使用录音时，识别到的表达式按当前笔色写入白板，并保留在表达式输入框供后续计算。
- 用普通画笔在手写字词上快速往返涂抹，能明确定位字词时，完整笔迹和涂抹痕迹会一起删除。可以一次撤销。键入或识别后写入白板的文字保留，工具栏可关闭「涂抹删除」。
- 在表达式框输入算式，选中一个子表达式后可用「储存／换元」定义字母。计算器与同题白板使用同一组变量。清屏只影响画布。能否计算或储存服从该题的计算器设置。
- 用套索圈住手写公式，可以拖动选区四角放缩。点「计算」会识别并计算所选公式。需要赋值时，点「识别圈选公式」，核对可编辑的结果，再输入或录音填写变量名。等式中可选一部分赋值。「赋值并换元」还会在画布上替换选区，替换可以撤销。
- 题目允许矩阵功能时，白板计算支持行向量和列向量、同形矩阵的加减、数与矩阵的乘除，以及尺寸相容的矩阵乘积。带小数逗号、分数系数和换行续写的表达式也可圈选计算。识别成功但暂时无法计算的原式会留在输入框中供编辑。
- 网站设置中默认允许圈选计算进行 CAS 化简，题目仍可限制计算器。打开白板后会提前加载题目允许的计算模块。圈选公式通过 AnnotationCapture 共享网关完成一次转写，再交给桌面和网站共用的计算引擎。网站按既有作答权限调用，服务端使用独立的网关会话。整题提交另按题意检查作答完整度。
- 首次使用「归档目录」，在桌面 Chrome 选定本机目录并允许写入。提交时保存 PNG 和可重新打开的画布、变量。在同题重新打开白板会读取最后一次存档。目录授权中断时保留当前画布，重新授权后可提交。
- 题目白板「提交」冻结画布并完成本机存档后上传本次图像做 OCR。识别到足够作答信息才交由当前学习、复习或题库的作答路由处理。难以辨认或缺少答项时，页面给出补充提示并允许继续编辑。
- OCR 默认使用已配置的判题提供方，必须支持图像输入。需要独立图像模型时，可在服务的环境中配置 `GRASPMEMOEDU_WHITEBOARD_OCR_API_KEY`、`GRASPMEMOEDU_WHITEBOARD_OCR_BASE_URL` 和 `GRASPMEMOEDU_WHITEBOARD_OCR_MODEL`。图片不进入学习数据库，作答记录保存经 OCR 得到的文本。
- 生产可通过 `deploy/98-openai-vision.conf` 启用独立的 OpenAI 视觉模型。它沿用网站已经部署的 OpenAI SSH 转发和 TLS 校验。未单独配置白板 OCR 时，白板提交优先使用此视觉模型。公式框选走 AnnotationCapture 网关，由该网关配置识别模型。
