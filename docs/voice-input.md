# 语音输入

一次录音累计最多 2 分钟。录音浮窗显示已录时长和上限。暂停时停止计时，继续时累加。点「转写」不重置计时。到上限会自动结束并转写最后一段。

浏览器兼容验收可在隔离站点运行 `scripts/voice_mobile_browser_acceptance.py`，分别选择 Chromium 和 WebKit。验收使用合成麦克风，检查暂停、自动停止、真实 MP4 或 WebM 解码以及最终插入位置。

登录后，在文本框或计算器输入区放好光标，点工具栏的麦克风。说话时后台提前识别当前段，点「转写」才显示这一段的完整结果。麦克风继续录下一段，可在上一段仍在结算时再次点击。各段按录制顺序出现在光标或选区，结束时处理余下内容并一次写入。暂停会停止当前的音频采集。取消恢复原选区。录音期间如手动编辑了原文，可以另选位置插入最终结果。

光标未落在可输入的位置时，只有 Topic 当前最新一页存在可作答的题目才显示录音入口。此时转写文字会进入[答题转换](answer-conversion.md)，自动填写原答题控件，之后可以修改并提交。

复现类答题可以在录音时或转写中点提交。提交会结束仍在进行的录音，转写成功后沿用原判题入口。转写失败时可以重试并继续原提交。同一题上的重复点击合并为一次提交。切题、关闭页面或更换账号会取消尚在等待的自动提交；留在同一页面时，仍可手动取回已转写的内容。

录音按钮只显示在当前工具栏。有题目工具栏时，录音与计算器等工具合在同一栏，计算器打开后仍可操作。设置等页面使用内容区工具栏，打开对话框后使用对话框内的工具栏。

普通文本框、答疑 Markdown 编辑器、图文答题框和公式内部都能原位显示临时结果。答疑草稿和公式编辑器在结束录音后写入一次，编辑器的撤销可以一起撤回这次听写。

在数学答题框口述“x 加三减 y”，结束后会写入可编辑的 \(x+3-y\)。分式、积分和矩阵使用公式排版，中文说明保留在相邻文字中。原样判分的输入框保留键盘写法，计算器使用自身的算式语法。系统只写学生口述的结果。其他文本沿用通用听写，邀请码等凭据字段只接受键入。

开始录音时，网站读取当前可见的完整题干和已显示的小问。直接在文本框听写时，光标前文、选中的原文和光标后文也会随录音提供给识别服务。计算器、公式编辑器和答疑框沿用各自的实际选区。例如框里已写“半径用 r 表示”，再说“半径等于五”，可以在光标处写入 r=5。识别服务只读取当前输入框，写入范围仍是开始录音时的光标或选区。

## 服务和维护

- 麦克风申请和 AudioWorklet 初始化并行。采集链启动后即可录音，识别连接在后台建立。支持 AudioWorklet 时持续发送 16 kHz PCM，后台保留临时结果，收到「转写」或结束操作后用服务商确认的完整段落结算。
- 浏览器保留每段原始音频，连接异常时可用完整文件转写。无法启动 AudioWorklet 时，兼容路径在同一麦克风轨上先开启下一容器，再停止上一容器，并在分段后用完整文件转写。
- 同一录音的各段依次转写。后续段可以用此前已转写的内容作为上下文。识别失败时保留音频供重试，静音段允许返回空结果。服务按现有登录和配额规则受理各次转写。
- Fun-ASR 最多接收五条各 400 字的上下文，较长题面保留首尾。整理模型可参考完整题干及光标前文、选区和后文各最多 4096 个 UTF-16 单元。常见算式沿用 cn2an、pypinyin 与 CMUdict 排版。
- 发布时先更新后端对分段请求的支持，再发布带版本签名的 Pages 静态资源。服务沿用现有识别和判题配置。

本地用 `scripts/calculator_browser_fixture.py --voice` 准备合成题库。分段验收检查点击前只上传音频并保持输入框原文、连续录音和按序写入。`scripts/voice_stream_browser_acceptance.py` 使用真实识别复核数学公式及上下文，记录打开麦克风和点击后显示的耗时。
