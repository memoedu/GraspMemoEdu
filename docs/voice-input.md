# 语音输入

登录后，在文本框或计算器输入区放好光标，再点工具栏的麦克风。说话时，文字会出现在光标处，有选区则在选区内显示。停顿时可以看到已说的部分，继续说话时，识别器能回改本次听写。说“周三，不对，是周五”这样的明确改口时，保留改正后的说法。结束录音后写入最终文字或公式。取消会恢复原选区；录音期间如手动编辑了原文，可以另选位置插入最终结果。

光标未落在可输入的位置时，只有 Topic 当前最新一页存在可作答的题目才显示录音入口。此时转写文字会进入[答题转换](answer-conversion.md)，自动填写原答题控件，之后可以修改并提交。

复现类答题可以在录音时或转写中点提交。提交会结束仍在进行的录音，转写成功后沿用原判题入口。转写失败时可以重试并继续原提交。同一题上的重复点击合并为一次提交。切题、关闭页面或更换账号会取消尚在等待的自动提交；留在同一页面时，仍可手动取回已转写的内容。

录音按钮只显示在当前工具栏。有题目工具栏时，录音与计算器等工具合在同一栏，计算器打开后仍可操作。设置等页面使用内容区工具栏，打开对话框后使用对话框内的工具栏。

普通文本框、答疑 Markdown 编辑器、图文答题框和公式内部都能原位显示临时结果。答疑草稿和公式编辑器在结束录音后写入一次，编辑器的撤销可以一起撤回这次听写。

在数学答题框口述“x 加三减 y”，结束后会写入可编辑的 \(x+3-y\)。分式、积分和矩阵使用公式排版，中文说明保留在相邻文字中。原样判分的输入框保留键盘写法，计算器使用自身的算式语法。系统只写学生口述的结果。其他文本沿用通用听写，邀请码等凭据字段只接受键入。

开始录音时，网站读取当前可见的完整题干和已显示的小问。直接在文本框听写时，光标前文、选中的原文和光标后文也会随录音提供给识别服务。计算器、公式编辑器和答疑框沿用各自的实际选区。例如框里已写“半径用 r 表示”，再说“半径等于五”，可以在光标处写入 r=5。识别服务只读取当前输入框，写入范围仍是开始录音时的光标或选区。

## 服务和维护

- 支持 AudioWorklet 的浏览器采集单声道 16 kHz PCM。直接听写按 50 毫秒打包，其他路由按 100 毫秒打包。录音图在支持的浏览器使用静音输出设备，减少声卡播放缓冲带来的等待。聚焦文本框时，启动请求携带 `live: true`。音频回执中的 `preview` 是本次录音的完整临时文本，后续版本可以替换或清空它。结束回执中的 `text` 是最终结果。计算器沿用算式整理，直接听写普通文字保留原话与标点。暂停会结算当前音频段，继续时保留前文；同一段的重发以字节位置去重。结构化答题命令在录音结束后统一填入控件。[Fun-ASR 服务端事件](https://help.aliyun.com/zh/model-studio/fun-asr-server-events)
- Fun-ASR 最多接收五条各 400 字的上下文。识别时给光标两侧、选区及本次已说前文预留空间，较长题面保留首尾。整理模型可参考完整题干及前文、选区、后文各最多 4096 个 UTF-16 单元。超长前后文取靠近光标的一端，超长选区保留两端。长文本只在开始录音时取一次。常见算式使用 cn2an、pypinyin 与 CMUdict 快速排版，更复杂的表达复用录音期间已完成的模型整理。
- 直接听写使用 WebRTC VAD 按 10 毫秒判断人声。连续静音达到 300 毫秒时，若云端仍有待确认的语句，网站主动取回结果；较短的口述片段保留 500 毫秒间隔，以容纳坐标或列表分量之间的停顿。再次开口时会带上起音前 250 毫秒的音频和本次录音的前文，继续写在同一处，允许后一句纠正前一句。[WebRTC VAD Python 绑定](https://github.com/daanzu/py-webrtcvad-wheels)
- 音频时长上限是 120 秒。浏览器保留本段音频供显式重试。缺少 AudioWorklet 时沿用共享的 MediaRecorder 与整段转写接口。服务器按登录身份和整段录音的额度受理，音频不进入备份。完成回执在内存中短暂保存 30 秒，用于停止请求的重发。
- 通用正文整理提示取自 AsyncWorkflow `4a7bf0aa0f05c01da8bb0439b450aa7a271dad67` 的 `src/async_workflow/prompts`。答题命令与计算器算式各自使用网站已有生成服务，直接处理语音识别原文；答题命令还使用当前题目的控件标签和可见选项。浏览器不发送输入框原有的文字。
- 站点发布须同步后端、nginx 中两个转写路由的请求上限和超时，以及 Pages 中带版本签名的静态资源。服务通过既有 `GRASPMEMOEDU_ASR_API_KEY` 和 `GRASPMEMOEDU_JUDGE_*` 配置连接，凭据不进入代码或构建产物。

Topic 最新页上无输入光标时，结构化题目把语音识别原文直接交给答题转换。明确的数值、选项和配对可直接匹配；需要理解口述时，同一次模型调用完成口语整理和控件映射。只说第 2、3 空时，仅更新这两个空。自由文本答案和有光标的听写仍按对应输入位置整理文字。

本地回归入口为 `tests/test_voice_stream.py`、`tests/test_training_audio.py` 和 `scripts/voice_input_browser_acceptance.mjs`。在已配置网站转写服务的隔离环境中，使用 `scripts/calculator_browser_fixture.py --voice` 准备合成题库，`scripts/voice_stream_fixture_audio.ps1 -OutputDirectory <空目录>` 生成测试录音。`scripts/voice_stream_browser_acceptance.py --help` 提供真实语音端到端验收入口。计时从合成录音最后一个可闻样本到公式绘制完成，另记停止按钮到写入的耗时。

文本框实时验收使用仅含合成题目的 `--voice` 环境。执行 `node scripts/voice_textbox_browser_acceptance.mjs <fixture> <录音目录> <报告.json> <本机服务地址>`。脚本在计算器和普通文本框分别回放停顿与改口，逐帧记录输入框文字，测量首字、停顿后的完整短语、改口替换和立即停止后的最终绘制。原有数学公式绘制计时继续由 `scripts/voice_stream_browser_acceptance.py` 验收。

新增工具按钮时，在 `web/question-tools.js` 管理的工具栏中追加，沿用现有图标按钮样式和键盘导航。
