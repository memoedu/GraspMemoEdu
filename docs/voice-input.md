# 语音输入

登录后，可在文本框或计算器输入区放好光标，再点工具栏的麦克风。录音可以暂停、继续或结束。转写结果插入开始录音时记录的光标处，有选区时替换选区。录音期间原文本有改动，或原输入框已关闭时，可以重新选择同类输入位置，再点击插入转写文字。

光标未落在可输入的位置时，只有 Topic 当前最新一页存在可作答的题目才显示录音入口。此时转写文字会进入[答题转换](answer-conversion.md)，自动填写原答题控件，之后可以修改并提交。

复现类答题可以在录音时或转写中点提交。提交会结束仍在进行的录音，转写成功后沿用原判题入口。转写失败时可以重试并继续原提交。同一题上的重复点击合并为一次提交。切题、关闭页面或更换账号会取消尚在等待的自动提交；留在同一页面时，仍可手动取回已转写的内容。

录音按钮只显示在当前工具栏。有题目工具栏时，录音与计算器等工具合在同一栏，计算器打开后仍可操作。设置等页面使用内容区工具栏，打开对话框后使用对话框内的工具栏。

语音输入不会执行计算。算式转写使用非写作模式，只接受符合格式的数学符号和词元。作答同样跳过写作分类，保留学生原本说出的推导和答案。其他文本沿用工作台的通用写作／非写作提示，输出可直接插入的正文。邀请码等凭据字段只接受键入。

## 服务和维护

- 浏览器录音、暂停、继续、媒体格式选择和音频摘要由 `web/microphone-recorder.js` 提供。DecisionWorkbench 从这个文件同步浏览器模块，沿用原有原生录音、上传、离线队列和文件转写。
- 网站通过现有 Fun-ASR 转写服务处理录音。服务器使用 FFmpeg 把浏览器音频转换为单声道 16 kHz PCM。音频每段最多 120 秒。上传受既有登录身份、每分钟调用和每日费用额度限制。网站服务在请求期间处理音频，录音不进入站点备份或工作台归档。
- 提示正文取自 AsyncWorkflow `4a7bf0aa0f05c01da8bb0439b450aa7a271dad67` 的 `src/async_workflow/prompts`。网站以自己的生成服务处理口述正文，沿用站点的模型连接配置。答题和计算器分支仅调用生成。生成模型接收原始转写片段，浏览器不发送输入框原有的文字。
- 站点发布须同步后端、nginx 中两个转写路由的请求上限和超时，以及 Pages 中带版本签名的静态资源。服务通过既有 `GRASPMEMOEDU_ASR_API_KEY` 和 `GRASPMEMOEDU_JUDGE_*` 配置连接，凭据不进入代码或构建产物。

以后可单独评估压缩 Topic 无光标场景的录音流程。方案是调整提示词，让语音识别的逐字文本直接进入答题转换，在原文字转答题命令的一次生成调用中一并处理口述格式。实施前用配对的完整说法与简写、负数与多变量选项、多个空和混合控件对照当前流程，核对转写后实际填入控件的准确性。当前保留现有转写和文字整理。

本地验收入口为 `tests/test_training_audio.py`、`scripts/calculator_browser_fixture.py` 与 `scripts/voice_input_browser_acceptance.mjs`。浏览器验收使用合成麦克风和隔离题库，正式转写服务使用独立的合成音频验收。

新增工具按钮时，在 `web/question-tools.js` 管理的工具栏中追加，沿用现有图标按钮样式和键盘导航。
