# 答题转换

在题目的「用文字填写答题控件」中输入答案，点击「转换」或按 Ctrl+Enter。填入后的选项、连线、各空或文字答案可以继续编辑。确认后点击原有 Submit 提交。

- 配对可写「左边第一个连右边第三个，左边第二个连右边第二个」，也可写「左一配右三，左二配右二」或 `1->3, 2->2`。只指定部分配对时，已有且不冲突的配对会保留。
- 单选可输入选项文字或字母。数字与某个选项精确对应时立即选中。省略变量名时也可写 `3` 或 `3，5`，服务端按选项中的赋值顺序匹配，要求结果唯一。
- 多个空可以按顺序用逗号、分号或换行写全，也可写「第三空填 8」。有分节导航的组合题以当前可填写的分节为范围。
- 在计算器中完成计算后，点击底部的「转换」可将当前结果直接填入该题。数值、表达式和有文本结果的计算模块支持转换。题目提交前仍可手动调整。
- [语音输入](voice-input.md)在无可输入光标且 Topic 最新页面可作答时，也能直接填入当前答题控件。图片转文字采用同一个入口，待接入 OCR。

文字转换沿用答题控件的草稿、权限与提交逻辑。需要 API 协助时，接口接收转换框文字和用于识别的控件标签或选项，使用站点已有的模型连接配置。模型回退受现有按学习者的频率限制和每日费用额度约束。转换不发送提交请求，不产生判题或学习进度。
