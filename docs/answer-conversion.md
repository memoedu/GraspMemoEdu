# 答题转换

题目下方的文字答题框默认关闭。要键入答题命令，在头像菜单的「设置」中勾选「显示文字答题框」，点击「保存」。这个选择按学习身份保存。关闭时仍可通过计算器或录音填写答案。

开启后，在题目的「用文字填写答题控件」中输入答案，点击「转换」或按 Ctrl+Enter。三种输入方式填入的选项、连线、各空或文字答案都可以继续编辑，确认后点击原有 Submit 提交。

- 配对可写「左边第一个连右边第三个，左边第二个连右边第二个」，也可写「左一配右三，左二配右二」或 `1->3, 2->2`。只指定部分配对时，已有且不冲突的配对会保留。
- 单选可输入选项文字或字母。数字与某个选项精确对应时立即选中。省略变量名时也可写 `3` 或 `3，5`，服务端按选项中的赋值顺序匹配，要求结果唯一。
- 多个空可以按顺序用逗号、分号或换行写全。只改部分空时，写出或说出空号，例如「第二个空填 7，第三个空填 -4」。系统只改这两个空，第一空保留原值。组合题以当前分节为范围。
- 在计算器中点击「转换」后可以继续计算。多空题从第 1 空起逐次填入。点选题中某个空位后，蓝框标出固定目标，计算器显示空号。此后每次转换都从这个空位起填，直到点选其他空或换题。
- 一个选项包含多个计算值时，每算完一个中间值点「记录」。最后一个值算出后直接点「转换」，系统按记录顺序加上当前结果匹配选项。点「撤回末值」可纠正记录。转换成功后记录清空，原答题控件仍可调整。
- [语音输入](voice-input.md)在无可输入光标且 Topic 最新页面可作答时，也能直接填入当前答题控件。图片转文字采用同一个入口，待接入 OCR。

文字转换沿用答题控件的草稿、权限与提交逻辑。需要 API 协助时，接口接收本次输入的文字和用于识别的控件标签或选项，使用站点已有的模型连接配置。模型回退受现有按学习者的频率限制和每日费用额度约束。转换不发送提交请求，不产生判题或学习进度。
